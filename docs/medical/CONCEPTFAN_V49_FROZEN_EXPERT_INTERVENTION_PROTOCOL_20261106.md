# ConceptFAN V49 — проверяемое экспертное исправление концепта с независимым reference

**ПРОТОКОЛ ЗАФИКСИРОВАН 6 ноября 2026, ДО V49 TEST.** Родительская V48 на четырёх независимых синтетических приборах показала: «усиление» концепта ограниченной log-odds связью дало небольшое несигнификантное улучшение на healthy, но вызвало серьёзную деградацию в неизвестном OFF-only drift. Нельзя выбирать новые параметры по V48 TEST и выдавать новый вариант за решение проблемы наблюдаемости.

## Вопрос и гипотеза

**Не** пытаемся получить физический смысл из одних ON/OFF показаний, если математически он неидентифицируем. Проверяем, можно ли явно учитывать **внешнее экспертное измерение концепта** и за ограниченный бюджет исправлений снижать ошибки интерпретации/прогноза, не теряя строгий concept-only risk bottleneck.

Реализуем API на frozen joint V48, который не тренирует модель и принимает действие: \`keep\`, \`confirm\`, \`reject\`, \`replace\`. Полезный доверенный \`reject\` немедленно возвращает **точный исходный K2**. \`replace\` c физически независимо подтверждённой новой membership меняет **только** signed contribution \(\gamma[f(q_{\rm corrected})-f(q_{\rm prior})]\), не raw encoder, все остальные концепты/веса/другие примеры неизменны. Для \`replace\` и \`reject\` требуется непустой внешний \`reference_id\`; без проверенного evidence операция запрещена. \`confirm\` сохраняет исходный прогноз и provenance; \`keep\` — отсутствие эксперта. При отсутствии измеренной поддержки q либо dual-VALID отказе запрещено насильно ввести значение через поправку. Нельзя изменять выборку ретроспективно по TEST Y или скрытому источнику.

## Фиксированная идеализированная экспертная reference (только синтетика)

Для оценки, а не для модели, TRAIN искусственного прибора имеет отдельный постфактум измеряемый физический скаляр \`true_slow_source_energy_POSTFIT_AUDIT_ONLY\`. **Это не реально доступный датчик в данных и не известная клиническая метка**; у симулированного эксперта условно есть независимое дорогое референсное измерение на выбранном TEST эпизоде.

На TRAIN имеем frozen исходный measured q V44 и внешний scalar E. Регистрируем только одно преобразование physical -> expected membership: стандартизуем E по TRAIN median и max(0.2, TRAIN IQR/1.349), затем только на *наблюдаемых q* оцениваем линейную least-squares \(\logit(q)\approx a\,E_{\rm standardized}+b\). Для сертификата TRAIN: >=200 наблюдений, корреляция \(\rho(q,E)\ge0.35\), наклон \(0.15\le a\le10\). Если не выполнено — независимый эксперт **недоступен** для прибора (никаких вмешательств). TRAIN-порог референсного несовпадения = max(0.05, 95-й перцентиль \(|q-\operatorname{sigmoid}(aE'+b)|\) на реально поддержанных TRAIN); независимо от Y, по TEST не меняется.

Для **выбранного** эпизода синтетический эксперт измеряет E и сообщает одно \`reject\` если \(|q-\hat q_{\rm reference}|>\tau_{\rm TRAIN}\), иначе \`confirm\`. Само E и \(\hat q_{\rm reference}\) НЕ поступают в модель/выбор проверяемого эпизода. \`replace\` тестируется алгебраически, **не участвует** в основном V49 benchmark, чтобы ограничить гипотезы.

## Фиксированный протокол отбора на проверку

Budget B = 0%, 10% или 20% от **всех** TEST эпизодов, округляем вниз; кандидаты только с уже используемым новым концептом в frozen V48. Если поддержанных меньше B*N — проверяем всех доступных. \`active\` без Y/reference: отбирает top-B по абсолютному logit-изменению \(|\logit(p_{\rm V48})-\logit(p_{\rm K2})|\); фиксированный порядок при равенстве — исходный индекс. \`random\` — ровно то же число из тех же eligible эпизодов, три независимых фиксированных RNG-повтора для каждой комбинации device/seed/case/mask/budget, никакой ручной подгонки. \`reject\` применяет точный K2, \`confirm\` сохраняет V48. При B=0 ровно frozen V48.

Контроль с тем же reference: RAW_DIFF_HGB_ALL1800 + тот же экспертный verdict, выбор для HGB — |logit(p_HGB)-logit(p_K2)|, на доступных **V48 measured q** эпизодах, fallback K2. Это дополнительный гибрид с внешней ConceptFAN-системой измерений и исходным K2; **не чистый baseline HGB**. Отдельно показываем чистый HGB1800. Он использует 1800 Y labels против TRAIN1000 для ConceptFAN, бюджеты не равны; выводить это явно.

## Свежие данные, TEST и отчёт

Четыре новых прибора **20262907/09** (linear_AR), **20262921/23** (nonlinear_switching), 1000 TRAIN, две независимые VALID по 400, 600 TEST; 3 native seed 11/23/37. Baseline V48-прогон идентичен зафиксированному до TEST оригинальному V48, только заменённые **new device seeds** и запись физических scalar E в отдельный sealed audit файл после обучения. 4 сценария: healthy_energy, common_U8_matched, unknown_OFF_drift, OFF_source_leak; 4 маски: MCAR20, MCAR40, MCAR50, missing_reference. Для каждого case одинаковые TEST исходы и маски K2 across arms.

Пять заранее фиксированных paired-AUPRC контрастов на каждый прибор (399 парных patient-bootstrap; smoke 199):
1. unknown_OFF_drift/MCAR40 active20−no_review;
2. unknown_OFF_drift/MCAR40 active20−random20 (средние 3 fixed random repetitions);
3. healthy_energy/MCAR40 active20−no_review;
4. common_U8_matched/MCAR40 active20−no_review;
5. unknown_OFF_drift/MCAR40 HGB1800+active20−HGB1800.

У всех: TEST AUPRC, NLL, Brier, доля покрытия, доля ревью/отказов/подтверждений, actual label-free priority, отказ по сертификату, тяжёлые отрицательные случаи. Сохранить все индивидуальные probabilities и truth (только audit), референс TRAIN и TEST отдельно, решения эксперта, train thresholds, dual-VALID gates, 20 pre-registered CI и оригинальные frozen 36 torch checkpoints. Независимый аудитор повторно пересчитывает метрики, механизмы применения \`reject\`/K2 и selected-mask без Y и без доступа к генератору. Не выбирать успешные TEST и не менять критерии после просмотра. Даже успех с идеальной synthetic reference **не** докажет, что сама модель автоматически обнаруживает физические концепты; это проверка открытого канала вмешательства.
