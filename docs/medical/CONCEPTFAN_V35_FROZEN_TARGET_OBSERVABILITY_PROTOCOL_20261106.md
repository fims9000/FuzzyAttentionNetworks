# ConceptFAN V35: frozen target-specific observability protocol
Registered 2026-11-06 before new synthetic TEST. Parent V34 branch PR #31. Earlier experimental results, accepted PIERE/IITI and master unchanged.

## The mathematical question
Observed linear mixed source data: y_M = H_M s + epsilon_M, epsilon Gaussian with known positive noise covariance R_M. Wanted concept c=l^T s. **c is structurally identifiable iff l belongs to rowspace(H_M)**, equivalently l is orthogonal to nullspace(H_M). This condition is strictly weaker than rank(H_M)=number of all sources. When c is identifiable, whitened generalized least squares has conditional variance l^T (H_M^T R_M^-1 H_M)^+ l. If c is NOT identifiable, the pseudoinverse's numeric answer is NOT a recovered concept. These are known linear inverse-problem facts, not new theorems. The calibrated mixing matrix is required; correlations alone cannot determine source orientation, causal role or physical identity.

Given a measured source membership mu(a)=sigmoid((a-tau)/w), and signed gamma, a conditional 1.96-SE amplitude radius has logit-effect sensitivity at most |gamma|*1.96*SE/(4*w), by the sigmoid Lipschitz constant. This algebraic statement is NOT a certified population risk bound or distribution-free confidence interval when calibration H,R are estimated.

## Predeclared falsifiers
Only sensor4 (a1+a2) or sensor5 (a2) visible: target a1 is NOT identifiable; target-rowspace rejects irrespective of observed fraction. Only sensor6 (direct a1) visible: a1 IS identifiable even though full two-source matrix is rank1; full-rank rejects, target-rowspace may accept. Sensors4+5: rank2; target identifiable. Complete sensor outage yields EXACT K2. Unseen all-source polarity reversal is observationally compatible with different latent signs; residual-only monitor cannot universally identify it. Single-sensor inversion is detectable only with redundant conflicting readings; if only sensor6 visible the monitor has no independent check.
