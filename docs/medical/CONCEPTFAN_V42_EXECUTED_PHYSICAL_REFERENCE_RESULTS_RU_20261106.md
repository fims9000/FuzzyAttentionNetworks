# ConceptFAN V42 — правильность физического значения концепта, а не только доля принятых измерений

**6 ноября 2026. Синтетическое исследование, выполнено и проверено.** [До TEST зарегистрированный протокол](./CONCEPTFAN_V42_FROZEN_PHYSICAL_REFERENCE_VALIDITY_20261106.md) и [PR #39](https://github.com/fims9000/FuzzyAttentionNetworks/pull/39), Draft. [Первый полностью успешный научный запуск 42225423702](https://github.com/fims9000/FuzzyAttentionNetworks/actions/runs/42225423702), [сырой экспериментальный артефакт](https://github.com/fims9000/FuzzyAttentionNetworks/actions/runs/42225423702/artifacts/13504274867). Это не медицинская диагностика, не проверка физически независимого реального оборудования и **не** теорема об идентифицируемости без разметки.

## 1. Что проверяли и зачем потребовался новый контроль

V41 увеличил число эпизодов, где хватает пары действительно измеренных независимых видов датчиков, но **это не проверяло, совпадает ли автоматически найденный концепт с физической величиной**. Концепт V41 — безразмерное \(q\in[0,1]\), отражающее энергию одного из выделенных временных режимов; высокая AUPRC задачи Y и согласие датчиков не подтверждают правильного физического имени и единиц измерения.

Здесь введён **новый, отдельный физический источник информации**, недоступный V41: независимый *симулированный* измерительный ориентир

\[
R_i=E_i+\eta_i,\qquad
E_i=\frac{1}{16}\sum_{t=1}^{16}(S_{i,0}(t)-\bar S_{i,0})^2,\qquad
\eta_i\sim\mathcal N(0,(0{,}10\,\mathrm{IQR}_{\rm TRAIN}(E))^2).
\]

Где \(S_{i,0}\) — истинный медленный латентный фактор, известный **только симулятору**. Таким образом R создан **программно из истины**; нельзя выдавать его за реально установленный калиброванный датчик. В будущем в реальной системе R пришлось бы получать из физически независимого прибора, испытывать его шум и стабильность. Доступ R делает этот режим **физически привилегированным обучением, не fully unsupervised**.

Новая процедура: V41 как прежде **без** R/H/S/Y учится восстанавливать статистические \(q_{AB},q_{AC},q_{BC}\) из действительно измеренной разности ON−OFF. Затем на **300 TRAIN** эпизодах с независимым R для каждой пары отдельно строится монотонная изотоническая калибровка \(m_p(q_p)\to\widehat R\), только при \(\rho_{\rm Spearman}\ge0{,}35\), ≥80 опорных измерений. На **200 VALID1** калибруется 90%-й *по номиналу* интервал остатков относительно **шумного R**, а на **других 200 VALID2** проверяются заранее заданные условия: покрытие R ≥75%, \(\rho\ge0{,}25\) и MAE ≤0,65 TRAIN-IQR(R), каждый после ≥50 реально наблюдавшихся пар. Никакого изменения этих порогов после просмотра TEST.

При TEST никакой R или истинный S модели не доступен. Выбор пары остаётся прежним V41 (число реально измеренных точек, проверка согласованности всех доступных пар, TRAIN-согласованная статистическая шкала), затем **физическая оценка** выдаётся только если **именно выбранная пара** прошла внешний TRAIN и две VALID. Показаны: физическая энергия в шкале R; интервал для шумного R; выбранная пара; число измеренных времен; предупреждение об одиночной, не проверенной другой парой, оценке; причина отказа. Историческая калибровка **не означает текущую независимую проверку исправности**.

**Критическое различие:** номинальный 90%-й интервал калибруется по R. Он НЕ имеет заявленной универсальной 90%-й гарантии ни для истинного скрытого E, ни условно на конкретном пациенте, ни при распределительном сдвиге. На TEST мы независимо **аудируем**, входит ли E в этот интервал, и показываем провалы.

TRAIN1000 + VALID400 + VALID400 + TEST600 для каждого прибора. В физическом контроле используются лишь 300+200+200 **дополнительных привилегированных опорных измерений**, не все валидирующие записи. 8 зафиксированных физических неисправностей и законов исхода × 7 масок наблюдений, всего **224 экспериментальных набора** по 600 TEST-эпизодов = **134 400 оценок** (те же люди повторяются при разных неисправностях). Контрольные условия включают MCAR20/40/50, полную потерю A/B/C, исчезновение OFF, неожиданное нарушение источникового переключателя, общую source-aligned помеху и сбой, известный уже во второй VALID.

**V42 не обучал ещё 12 новых Transformer:** эта задача исследует собственно физическое значение уже имеющегося сенсорного концепта, а не качество модели исхода Y. Реальный native K2/его risk head изучены отдельно в V40/V41, новый TEST Y тут не используется ни в source fit, ни в калибровке. Поэтому нельзя приписывать V42 рост AUPRC или новую обученную архитектуру: улучшен **измерительно-семантический модуль**.

## 3. Явный критерий ошибки и корректный знаменатель

Заранее зафиксирован диагностический критерий *существенной физической ошибки*:

\[
\left|\widehat E_i-E_i\right|
> 0{,}5\,\operatorname{IQR}_{\mathrm{TRAIN}}(E).
\]

Это выбранный **исследовательский масштаб** ошибки, а не общепринятый допустимый медицинский порог. Долю «ошибочно принятых» считают **только среди тех TEST-эпизодов, на которых V42 действительно выдал физическое значение**. Отдельно выводится доля всех TEST, где концепт был принят. Нельзя сравнивать выборочно отобранные доли ошибок и делать вывод обо всех пациентах без учёта изменения покрытия.

## 4. Исправные приборы: даже валидированная ссылка на R не идеальна

Исправный TEST с MCAR20:

| Прибор | Покрытие физически откалиброванными оценками | Ошибка >0,5 TRAIN IQR среди принятых | Нормированная физическая MAE | Доля истинных E внутри интервала для шумного R |
|---|---:|---:|---:|---:|
| Линейный 607 | 87,5% | **22,3%** | 0,388 | 92,8% |
| Линейный 609 | 88,5% | **25,2%** | 0,438 | 89,1% |
| Нелинейный 621 | 84,7% | **25,4%** | 0,429 | 91,3% |
| Нелинейный 623 | 87,7% | **19,2%** | 0,349 | 95,8% |

На всех четырёх приборах историческая калибровка AB/AC/BC прошла оба VALID. В исправном режиме получаем умеренную, но не точную физическую оценку. Аудируемая фактическая **Spearman-корреляция с E среди принятых** составила ~0,768–0,843. Это не идентичность «концепт = физический фактор».

Интервалы на этом узком исправном синтетическом законе включали истинную E в ~89–96% принятых эпизодов; ещё раз, они **не были по построению калиброваны к E**, и такое эмпирическое сходство с 90% не является общей гарантией.

MCAR40:

| Прибор | Принято со шкалой R | Физически существенная ошибка среди принятых | Из принятых одна, не corroborated пара |
|---|---:|---:|---:|
| 607 | 16,0% | 32,3% | 84/96 |
| 609 | 18,5% | 36,0% | 94/111 |
| 621 | 17,5% | 26,7% | 94/105 |
| 623 | 14,3% | 20,9% | 75/86 |

При MCAR50 принимаются только 5, 7, 5, 17 из 600 эпизодов. Доли ошибки на столь малых отобранных подмножествах **нельзя считать надёжными показателями** физической точности. Генеративное восстановление отсутствующего OFF не использовалось и не выдавалось за реальное измерение.

При потере *всей одной* измерительной группы парная адаптация переходит на оставшуюся пару, часто почти со 100%-м покрытием. Однако тогда каждый такой эпизод в принципе **не имеет текущего согласования с альтернативной парой**; это нужно показывать пользователю даже при удачном TRAIN и VALID.

## 6. Отрицательный результат, который меняет интерпретацию метода: неизвестный дрейф OFF

В TEST физически меняется приборная помеха **только** в OFF. Истинная медленная компонента E и метки испытуемого остаются теми же. Три пары по-прежнему могут выглядеть взаимно согласованно — все они получили общую ошибку.

| Прибор | Принято при неисправности | Физически неверно среди принятых | Нормированная MAE | Истинная E внутри прежнего R-интервала |
|---|---:|---:|---:|---:|
| Линейный 607 | 78,2% | **79,3%** | 1,609 | 35,8% |
| Линейный 609 | 79,0% | **80,0%** | 1,725 | 40,1% |
| Нелинейный 621 | 81,8% | **83,5%** | 1,898 | 36,3% |
| Нелинейный 623 | 86,7% | **83,7%** | 1,641 | 42,3% |

**Именно это — главная отрицательная находка V42.** При неизвестном нарушении аппаратной предпосылки «одинаковая помеха в ON и OFF» модель часто очень уверенно выдает физический концепт, ошибочный по известному симулятору. Включённый однажды в TRAIN эталон R и две исправные VALID **не устанавливают исправность OFF сейчас**.

Парный bootstrap на **одних и тех же TEST людях, принятых и в исправном режиме, и при неисправности**, даёт увеличение нормированной на TRAIN-IQR истинной MAE (не AP!) в мире OFF-drift − healthy:

| Прибор | Рост физической MAE в TRAIN-IQR | 95%-й парный интервал |
|---|---:|---|
| 607 | +1,240 | [1,116; 1,368] |
| 609 | +1,294 | [1,111; 1,471] |
| 621 | +1,498 | [1,336; 1,649] |
| 623 | +1,303 | [1,184; 1,446] |

Все четыре заранее зарегистрированных интервала положительны. Но это **внутри конкретных синтетических устройств и когорты**, не доверительный интервал по всем будущим приборам. Процедура парного сопоставления устраняет расхождение состава принятых для этой конкретной разности, но не делает принятые подвыборки репрезентативными для всех пациентов.

**Если тот же OFF-only дрейф известен уже в VALID2:** каждая из 12 проверок (четыре прибора × три пары) **отклоняет новую физическую калибровку**, тестовый physical source use становится 0. Это корректный отказ при известной неисправности, но не свидетельство универсального обнаружения новой неисправности.

**Если OFF не измерен:** физическая оценка на всех 600 TEST-эпизодах по каждой зарегистрированной ситуации отсутствует, никаких «заполненных» величин нет. Независимый аудит подтвердил 16 800 таких отказов среди всех четырёх приборов и семи масок.

## 7. Сильная общая помеха и нелинейный тракт

При одинаковой общей source-aligned помехе ×8 в ON и OFF **линейные** приборы дают практически точно ту же нормированную физическую MAE, что исправное состояние. Поэтому вычитание по-прежнему помогает *при выполненных физических предпосылках*.

Но в **нелинейных** приборах ошибка растёт по тем же принятым испытуемым: +0,060 TRAIN-IQR [0,039;0,081] и +0,075 [0,055;0,099]. Нелинейное \(g(x_{\rm ON})-g(x_{\rm OFF})\) уже не равно входному сигналу: неизменность прибора не гарантирует точного сокращения полезной и общей частей при предварительной нелинейности.

При 50% утечке источника в OFF доля физически существенной ошибки при MCAR20 — **39–54%**, то есть существенно больше, чем без поломки. Успех TRAIN-ориентации не доказывает корректное действие физического переключателя в эксплуатации.

## 8. Реальная форма интерфейса и воспроизводимость

Добавлены:
- \`src/conceptfan_discovery/physical_reference_certificate_v42.py\`: отдельная внешняя физическая калибровка и TRAIN/VALID-гарантии уровня **шумного R**, source gauge из V41, отказ, безопасное JSON-сохранение/загрузка без pickle; при TEST нет R/H/S/Y в API.
- \`src/conceptfan_discovery/physical_reference_world_v42.py\`: синтетическая независимая контрольная ветка R, точное разграничение TRAIN/VALID/TEST; ни латентный E, ни референс R не входят в измеренный source fit.
- \`scripts/experiment_physical_validity_v42.py\`: восемь физических сценариев × семь стрессов × четыре прибора, исходные TEST-массивы для последующей физической проверки, 32 фиксированных парных теста.
- \`scripts/audit_physical_validity_v42.py\`: независимый пересчёт физической правдивости по сохранённым individual TEST q/Rhat/E, счётчики физически ошибочных принятых, отказ при отсутствующем OFF, 32 парных бутстрэпа. **Численная ошибка всех пересчитанных метрик 0.0**.
- \`scripts/infer_physical_reference_v42.py\`: запуск на **новом \`.npz\` с настоящими ON, OFF и двумя BOOL-масками**, с генератор-независимым кодом. Выход — JSON: численная оценка энергии, интервал для R, пара/количество точек, предупреждения, причины отказа. Это **исследовательский инструмент**, а не нейросеть, умеющая автоматически подтверждать аппаратную исправность. Веса и риск K2 не переобучаются.
- \`scripts/verify_external_npz_physical_v42.py\`: отдельный QA реального NPZ→JSON тракта с повторной загрузкой JSON-словаря физической калибровки; сравнивает каждый вывод с неизменными ранее записанными TEST оценками. Генератор разрешён **только в QA-коде подготовки файла**, не в самом интерфейсе инференса.

Первый успешно исполненный независимый научный CI: [42225423702](https://github.com/fims9000/FuzzyAttentionNetworks/actions/runs/42225423702) с **27** тестами, четырьмя новыми приборами, всеми 224 сценариями и 32 парными проверками; воспроизведено 134400 TEST-измерений и все физические метрики, максимум расхождения 0.0. Далее в репозитории расширены тесты внешнего NPZ→JSON интерфейса и проверка фактического соответствия масок (дополнительный CI, исходные параметры научного алгоритма **не менялись**). Окончательную успешность этого отдельного инженерного проверки см. в PR/Actions; не нужно смешивать её статус с уже успешным первым научным экспериментом.

Ограничения: внешняя R-ветка сгенерирована из симуляторного E; физически сопоставимое измерение в реальном мире ещё отсутствует. Прямая raw HGB/градиентная регрессия по **той же независимой R-разметке** пока не сравнивалась; ранее V40/V41 HGB обгонял ConceptFAN по риск-AUPRC, но это **другая целевая переменная**. Следовательно, нельзя объявлять рекорд физического восстановления, общую нейросетевую новизну или превосходство над опубликованными моделями. Понадобится новый предварительно зарегистрированный эксперимент с обычным R-supervised сырым сигналом и настоящей физической калибровкой.

## Научный итог

В отличие от повышения AUPRC/частоты объяснений, V42 количественно проверяет **ложно принятые физические концепты**. Выяснилось, что в исправной синтетической среде при заранее заданном масштабе отклонения уже около одной пятой — четверти принятых значений имеют существенную ошибку, а при неизвестном OFF-дрейфе большинство принятых значений ошибочно, несмотря на успешную прошлую калибровку. Это не дефект, который можно закрыть ещё более высоким порядком нечётких функций: без текущей независимой физической информации два мира могут оказаться наблюдательно неразличимыми.

**Следующий уровень полезного исследования:** не ещё одна искусственная категория «уверенности», а *условия сохранения смысла физической шкалы при сдвиге приборов*, проверяемые внешними контрольными сигналами, экономией опорной физической разметки и честным сравнением с физически supervised raw-регрессорами. Работу не объединяли с master, старые V35–V41 results не переписаны.


## 9. Финальный внешний NPZ→JSON путь и побайтовая проверка V42

**[Последний успешный GitHub Actions 42226763854](https://github.com/fims9000/FuzzyAttentionNetworks/actions/runs/42226763854)**, source code SHA \`f6ff0da7cda173b9551cae934ab3c6685fe199da\`, [окончательный первичный артефакт 13505947205](https://github.com/fims9000/FuzzyAttentionNetworks/actions/runs/42226763854/artifacts/13505947205). **28 тестов пройдено**, успешно полный повтор эксперимента 224 условий × 600 эпизодов, пересчитаны все научные проверки физических ошибок с максимумом отклонения **0**, зафиксированы 16 800 обязательных отказов при недоступном OFF и все 32 заранее определённых парных бутстрэп-интервала.

Новый пользовательский интерфейс \`scripts/infer_physical_reference_v42.py\` загружает только \`on\`, \`off\`, \`observed_on\`, \`observed_off\` из NPZ с реальными двоичными масками, JSON-снимок модели TRAIN/VALID и возвращает JSON с оценённой величиной в шкале шумного R, интервалом, выбранной парой, числом реально измеренных временных моментов и **причиной отказа**. Сам модуль **не импортирует генератор**, не запрашивает истинные латентные S/H, реальные исходы Y или тестовое значение R; файл с неполным OFF не превращается в выдуманный физический сигнал. Поддерживается пакет из N=1..10000 эпизодов, входные измерения только при реальном \`observed=True\` обязаны быть конечными, маски — строго Boolean, выходной файл не переписывается. Библиотека source-проекций и исторической калибровки восстанавливается из JSON без произвольного pickle.

**Не отдельная демонстрация на вручную подогнанной паре:** независимый QA через основной пользовательский интерфейс заново открыл 48 сохранённых model×device×fault×mask условий, прочитал **576 реальных маскированных ON/OFF эпизодов**, где во всех физически отсутствующих ячейках были \`NaN\`, и сверил с **изначально записанными TEST-прогнозами**.
