# ConceptFAN V56 — frozen external-measurement corroboration and revocation study
**Registered before experiment code/results on 13 Nov 2026.** Research branch: `experiment/conceptfan-v56-independent-reference-20261113`. Base: audited V55, PR #57.

## Scientific question
V55 correctly builds and trains new **statistical** concepts but admits an outcome-predictive instrument artifact indistinguishably from a useful source. Can an *independent measurement of a declared target property* corroborate a new concept under limited assay budget, preserving exact K2 fallback when a highly predictive new source is unsupported or drifted? Crucially, this is a **conditional measurement claim**, not a proof of physiology or causality.

## Fixed design
- New independent seed `20265621`, distinct TRAIN/VALID/TEST subjects, 16x12 observed channels, no hidden generator sources passed to model. Three delayed sensor pairs: 4/5 even-energy candidate representing the externally measured target in the synthetic world; 6/7 signed distractor; 8/9 even-energy *recording artifact*. External assay is separately simulated from latent target energy with independently sampled measurement noise; it is not a copy of either sensor. Users of the algorithm see ONLY `(X,M,Y)` and purchased assay observations for TRAIN/VALID, **never** simulator factors or the TEST assay.
- Four registered label/evidence modes: `nonlinear_energy` (risk depends on energy in 4/5), `irrelevant_delays` (risk depends only on K2), `predictive_recording_artifact` (risk depends on energy in 8/9 although the declared external assay measures 4/5), and `reference_permuted` (same outcomes/X as useful case but corrupted TRAIN/VALID assay pairing). Same test subjects shared across two native initializations, not 2 independent cohorts.
- TRAIN950, VALID1 400, VALID2 400, TEST650; native seeds 11/23; all sources/operators from TRAIN X only; K2 and bounded V55 fits only TRAIN Y; predictive risk gate on both disjoint VALID Y using unchanged V28 rules.
- **Assay budget**: 190 randomly selected TRAIN external readings, plus 100 fresh VALID1 and 100 fresh VALID2 readings. Fit one TRAIN-only nonnegative linear mapping from q to external assay using only patients with measured q support >=.5. Require TRAIN nonconstant q and a positive slope. On each independent VALID reference cohort require Pearson correlation >= .55, improvement >= 10% in MAE over a **TRAIN-constant** assay predictor, and >= 65 supported assay episodes. Both VALID cohorts must pass. Fixed thresholds before TEST.
- Assay and prediction gates are distinct. Admit at most one candidate that passes both; choose by pre-existing predictive VALID score among admitted. Reject unknown, mismatched `physical_device_id`/`external_reference_id`, missing certificate, or missing source support to **bitwise exact K2**. Report `ASSAY_CORROBORATED_STATISTICAL_SOURCE` only, never `PHYSICALLY_PROVEN` or clinical/causal identity. Reference IDs are *configuration declarations* in synthetic tests, not cryptographic attestation.
- Additional source-only unlabeled cohort-shift monitor: TRAIN candidate-q mean and 399 train-bootstrap replicates of 200 supported episodes, with fixed two-sided envelope `max(.025, 1.5 * Q_0.995(|bootstrap_mean - train_mean|))`. At prediction time, if cohort lacks 100 supported patients or the mean q leaves the frozen TRAIN envelope, reject the **whole cohort** to K2. This is only cohort-level selective rejection; it does not infer individual sensor correctness. No TEST label access.
- Six registered TEST conditions: complete, MCAR20, MCAR40, sign flip of both selected paired sensor channels, 1.5x gain in both, and forced missing of candidate sensor observations. When no selected candidate exists, source stresses target the fixed 4/5 reference pair to keep a comparable no-admission control. 4 modes x 2 native seeds x 6 conditions = **48 saved TEST individual prediction arrays**.
- Compare K2, unrestricted V55, externally corroborated V56, and same-TRAIN-label raw/energy-engineered logistic; report TEST AUPRC, NLL, source use %, rejection reasons, useful-source retain vs artifact rejection, false refusal rate on healthy and shifted episodes. Save independent per-person predictions, source passports, all budget IDs and pair-wise dual VALID evidence.
- Independent audit must recompute 48 arrays' hashes, metrics, exact signed contribution and fallback, and paired descriptive 95% bootstrap across the same TEST subjects for the two native seeds; correct for no multiple comparisons in interpretation.

## Falsifiable negative controls and boundaries
- `reference_permuted` must not produce a passing measurement certificate; no retrospective TEST threshold changes if it does.
- If an instrument artifact accidentally correlates with the external target, evidence alone might fail to distinguish; the synthetic generator is designed to make it independent. This is not general physical-source discovery.
- A cohort TEST shift that preserves q's distribution or a rotation preserving all observations is statistically invisible to a q-mean monitor. Sign inversion of even-energy paired channels is exactly such a case; report it honestly, do not call it device-authenticated robustness.
- V56 may **sacrifice predictive AUPRC** in the artifact-label mode to avoid claiming an unsupported reference source; this is by design, not proof of predictive superiority.
- The external assay supplies additional supervision unavailable to raw baseline. Keep assay counts transparent. Correlation and reference ID do not prove physiological causality, semantic source identity, resistance to collusion or real-world attestation.
- If the declared target reference or device is missing at inference, the entire optional concept is rejected. The underlying native K2 remains independently trained and unmodified. No changes to earlier V53–V55 outcomes or publications.
