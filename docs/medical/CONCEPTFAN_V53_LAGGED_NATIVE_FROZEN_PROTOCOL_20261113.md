# ConceptFAN V53 — frozen before new GitHub Actions model outcomes (13 Nov 2026)

## Parent goal
Automatically form **causal-in-time but not causally identified** fuzzy concepts from previously unassigned measured time series, then admit at most one into the *native* ConceptFAN exact signed decision. No predefined physiologic source labels, source oracle, future-at-time-t readings, or TEST outcomes may participate in construction.

Prior checked findings: V17 dynamic source proposals are possible but colored sensor noise is an indistinguishable measured pattern; IOI auto-grouping 2026-11-06 improves task AUPRC on one synthetic family but fails test-only sensor sign shifts; V50 observational twins prove physical names cannot be inferred from X/Y. V52 runtime is an attested-physical-source integration **without a real joint training experiment in its own tests**. V53 addresses **temporal delayed sensor pairing and K2→K3 native automatic admission**, *not* V50 physical certification.

## Frozen mechanism
- TRAIN-only 3 disjoint subject folds, unknown channels 4–11, known K2 channels 0–3. Evaluate ordered sensor pairs and lags 1,2,3. Require minimum absolute cross-lag correlation .65 *in all three folds* and stable sign; require improvement over the maximum same-time absolute correlation >=.30. At most three disjoint pairs; retain exact observed sensor definition and train-only normalization. No supervised labels in this proposal stage.
- A concept c[t] uses only source sensor at t−lag and readout at t, never t+lag. Both readings must be actually observed. Fuzzy q[t] is sigmoid of their signed, normalized mean. Missing values produce q[t]=0.5 and availability=0. One episode-level q summarizes the last six time points with coverage shrinkage. The number of admitted concepts K is **2 or 3**, not always a manually forced 3.
- Native known K2 uses `TemporalConceptFANModel` inside `AnchoredJointConceptBottleneckV47`, trained for five TRAIN-only epochs via measured two-pair proxies, BCE +5×masked proxy MSE. No synthetic true concept trajectories; no risk bypass. Freeze its weights and baseline logits after training. For each discovered q fit exactly one TRAIN-only scalar gamma, preserving frozen K2 weights. For two independent VALID400 subject cohorts, require mean NLL gain >=0.003 and one-sided 99%-bootstrap lower gain >0, observed support >=75% of patients at threshold 0.50, exactly existing V28 admission implementation. Select at most one.
- On TEST, the same native model computes `logit=b+sum known signed contributions + I[VALID pass and availability] gamma(q−.5)`. Exact frozen K2 fallback for rejection/missing. No direct raw-to-risk bypass.
- Compare frozen K2, auto K3 and same-label-budget **raw logistic regression**; metrics AUPRC and NLL. No claims of predictive superiority without external data. Deliberately include a *predictive recording-artifact source* as negative semantic counterexample.
- Synthetic generator distinct from previously inspected V30: independent 16-step source streams; channels 4/5, 6/7, 8/9 are lag=2 source/readout pairs; channels 10/11 independent noise. Labels: (A) extra physiologic-labeled **synthetic** source + known K2; (B) K2-only with irrelevant delayed sources; (C) predictive device-artifact source + K2. Hidden source labels are used only to generate Y, never for discovery/prediction. TRAIN950 / VALID1 400 / VALID2 400 / TEST650, native initializations 11/23.
- TEST stress fixed before run: complete, MCAR20, MCAR40, unseen full sign inversion of the chosen candidate's source/readout channels, with identical known K2 inputs. The reversal can remain observationally unidentifiable from source-internal statistics; report degradation, do NOT fabricate a robust shift solution.

## Gate and reporting
1. All 7 unit tests of masked lag discovery must pass, plus native additive/fallback contract smoke.
2. New GitHub Actions run trains exactly six native K2 initializations (3 label modes ×2 seeds), fits candidates using TRAIN only, VALID-gates before TEST, then reports **all 24 TEST rows**, all refusals, full zero-signal baseline and source/passport receipts.
3. If no source is selected or TEST K3 loses on a held-out mode, report negative result. A matched clinical dataset, independent external physical measurements and new device families are required before calling any concept a physiological cause.
4. Never merge this explorative experiment into master or alter frozen earlier experiments. This is a separate research branch and does not rewrite accepted IOI/PIERE/Tver papers.

Scientific novelty claim is **not** automatic discovery itself, but a falsifiable combination of lagged observable operator definitions, reliability-neutral missingness, selective source-to-risk admission, and native exact concept-only decision with realistic negative controls. Prior art includes existing masked temporal concept-bottleneck methods; no priority asserted.
