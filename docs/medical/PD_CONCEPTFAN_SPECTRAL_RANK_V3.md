# PD-ConceptFAN v3: ранг динамики как источник числа концептов

**Статус: эксперимент.** Отрицательные результаты v1 и v2 сохранены.
Исходная принятая работа PIERE и проверенная ветка PR #2 не изменены.

## Почему MDL и masked reconstruction оказались недостаточны

В первой реализации число потенциальных слотов было 10. L0-штраф не
выключил ни один из них. Затем отдельный validation-отбор стабильно
оставлял 1 концепт как минимальное состояние для предсказания исхода,
будущих и намеренно скрытых измерений.

При этом задача бинарного предсказания допускает скалярную достаточную
статистику `P(Y=1|X)`. Поэтому **неправомерно** считать, что число
компонент, необходимое для данной метки, равно числу исходных
физиологических процессов. Нужна дополнительная структура, наблюдаемая
непосредственно из динамики.

## Новая математическая гипотеза

В ограниченном классе наблюдаемых линейных систем с независимым
во времени шумом измерений:

```text
latent[t+1] = A * latent[t] + disturbance[t]
measure[t]  = B * latent[t] + white_noise[t]
```

матрица ненулевых временных ковариаций

\[
\Gamma_\tau=\mathbb E[(X_t-\mu)(X_{t+\tau}-\mu)^T],
\quad \tau=1,2,3
\]

содержит информацию о *динамическом*, а не о просто мгновенно
коррелированном пространстве. Для

\[
\mathsf H=[\Gamma_1\mid\Gamma_2\mid\Gamma_3]
\]

ранг `rank(H)` не превосходит размера латентного состояния и при
дополнительных условиях наблюдаемости и возбуждения может быть ему равен.
Это частный случай классической идентификации линейных систем,
**не** общий метод доказательства медицинских причинных факторов.

В конечной выборке у H почти всегда полный численный ранг. Поэтому
число компонент выбирается НЕ произвольным порогом для singular
values, а **family-wise permutation-calibrated spectral noise floor**:

\[
K_{\rm dyn}=\sum_i\mathbf1\{\sigma_i(\mathsf H)>q_{.95}(\sigma_1(\mathsf H^\pi))\}.
\]

В каждой перестановке целая будущая траектория пациента сопоставляется
с прошлой траекторией другого пациента. Это сохраняет структуру
отдельных историй и наблюдаемости, разрушая соответствие динамики
одного и того же пациента. Порог *максимального* случайного singular
value один для всех компонент и консервативнее их отдельных квантилей.

Далее число компонент оценивается с повторной выборкой **пациентов**,
не пар соседних временных точек, которые зависимы.

**Важная граница:** это число *обнаружимых предиктивно-динамических
направлений*, а не автоматически найденное число клинических
патологий. При нелинейности, отсутствии наблюдаемости, общей
ненаблюдаемой причине, информативных пропусках и нестабильности
распределения результат может быть смещён.

## Воспроизводимый численный эксперимент без знания истинного K

Созданы два независимых синтетических набора для каждого из
`K_true = 3,5,7` с отдельными генераторами. Алгоритм получает
только TRAIN-временные ряды, маски пропусков, **не получает** меток
класса, истинных скрытых состояний или фактический K.

Результаты <https://github.com/fims9000/FuzzyAttentionNetworks/actions/runs/41498657019>:

| Истинное K (внешний контроль) | Train-only обнаруженное K | Повторы |
|---|---:|---:|
| 3 | 3 | 2/2 |
| 5 | 5 | 2/2 |
| 7 | 7 | 2/2 |

Сингулярный спектр, шумовые пороги, доверительные интервалы
пациентского bootstrap, независимый сравниваемый square-block-Hankel
алгоритм и подписи входных наборов сохранены в GitHub Actions artifact.

Это демонстрирует работоспособность rank-оценки на **данных этого
синтетического семейства**. Не утверждаем, что 6/6 демонстрирует
идентифицируемость для произвольных моделей или уверенность на
реальных пациентах.

## Как концепты теперь действительно создаются в процессе обучения

По train-only SVD берутся наблюдаемые направления `U[:,1:K_dyn]`.
Для каждого направления строится прозрачное определение через
подписанные измерения: положительные и отрицательные нормализованные
`level`-операторы с коэффициентами `abs(U[j,k])`, нормированными на 1.
Это **наблюдаемые**, не экспертно названные определения.

В нейросети вычисляется непрерывная траектория:

\[
c_{tk}=\sigma\left(
\frac{\sum_j w^+_{kj}\phi^+_j(X_t)
      +\sum_j w^-_{kj}\phi^-_j(X_t)-\tau_k}{s_k}
\right)\times r_{tk}.
\]

Обучаемые `tau_k` и `s_k` определяют точку и ширину перехода;
`r_{tk}` учитывает измерительную доступность. Можно зафиксировать
операторные определения или донастраивать их с регуляризацией
отклонения от наблюдаемого базиса.

**Оба выхода модели** используют эти же концепты:
- логит цели `bias + sum_k contribution_k` (строго точное разложение);
- прогноз будущих измерений и восстановление скрытых текущих показателей.

Преобразование SVD в ограниченную nonlinear tanh/sigmoid библиотеку
**не идентично исходной линейной матрице**; это новое проверяемое
индуктивное приближение. Одного совпадения спектральных подпространств
недостаточно для семантической валидности.

### Что именно сравнивается

1. `learned_10`: исходная v2 с десятью обучаемыми слотами и
   отдельным отбором K по половине validation.
2. `spectral_frozen`: K из train-only временного ранга, общие
   заранее выявленные определения, обучаемые пороги и решающая модель.
3. `spectral_finetuned`: тот же K и та же train-only инициализация,
   но разрешена ограниченная адаптация определений под задачу.

Обязательные метрики: AUPRC, прогноз будущих измерений, masked
reconstruction, покрытие planted states с поправкой за пропущенные
состояния, стабильность *case-specific* объяснений относительно
перестановочного пациентского контроля, количество меняющихся
концептов и точность аддитивного разложения.

**Предупреждение:** идеально одинаковые подписанные определения в
`spectral_frozen` одинаковы *по конструкции*. Это ещё не означает,
что модель даёт одинаковые, содержательные, индивидуальные
объяснения и предсказывает лучше. Сравнение с
`spectral_finetuned` и исходной моделью необходимо.

## Особая проверка на реальных ICU-данных

В `clinical_predictive_rank.py` впервые проверяется, стабилен ли
train-only динамический ранг по двум независимым подвыборкам
поступивших в реанимацию пациентов.

Никто не присваивает факторам названия заболеваний автоматически.
При нестабильности ранга или слабой согласованности подпространств
**нельзя** использовать этот K как подтверждённое количество
медицинских концептов. Раздельно выводятся дрейф наблюдаемости
(частоты измерений) и распределения самих сигналов.

Данные `calibration` и старые `test` не используются.
