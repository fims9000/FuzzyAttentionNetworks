# V34 — Предварительно зафиксированный протокол: адаптивные уровни нечёткости и условный flow для временных концептов

**Дата регистрации:** 2026-11-06, до создания новых TEST-результатов. **Исходная ветка:** \`experiment/ioi-synchronized-outages-concept-interventions-v33-20261106\`. Новый эксперимент НЕ изменяет результаты V30–V33, принятую PIERE и IITI. Все TEST-сценарии, абляции, пороги и начальные состояния определяются до получения результатов. Результаты должны публиковаться независимо от того, окажется ли Type-3 полезен.

## Предмет исследования

Не проверять бессодержательную гипотезу «Type-3 всегда лучше Type-2». Проверять, можно ли **независимо различать неопределённость траектории источника и неопределённость определения концепта между режимами измерения**, сохраняя точный аддитивный прогноз, документированное измерительное происхождение и право отказаться от нового концепта.

Ранее V32/V33 оценивали временной источник точечно по TRAIN-only масочному rank-1 шаблону. При независимых пропусках этот признак работал; при неизвестной инверсии приборов новый источник мог сильно ухудшить прогноз. Ни нечёткость высокого порядка, ни diffusion/flow сами по себе не устраняют наблюдательную неидентифицируемость при отсутствии информации. Любые заявленные гарантии ограничены сформулированными предпосылками.

## Объект Type-3

Построить **ограниченное интервалное Type-3 представление с дискретными α-плоскостями**, не выдавая простую неопределённость измерения за третье измерение нечёткости.

- Входная основная величина \`z\` — наблюдательно определяемая амплитуда временного источника, полученная по TRAIN-only группе датчиков.
- Type-1: \`mu(z)=sigmoid((z-tau)/w)\`, где \`tau,w\` определены без исходных меток.
- Interval Type-2: у каждого \`z\` область неопределённой степени принадлежности \`u∈[L2(z),U2(z)]\` из неопределённости реконструкции \`delta2\`. Это не вероятность.
- Restricted interval Type-3 **α-plane representation**: для заранее зарегистрированных \`alpha∈{.25,.50,.75,1.}\` дополнительная независимая неопределённость определения границы \`delta3\` расширяет Type-2 FOU: \`L_alpha=σ((z−tau−delta2−delta3*(1−alpha))/w)\`, \`U_alpha=σ((z−tau+delta2+delta3*(1−alpha))/w)\`. Требуется строгая вложенность всех α-полос, \`L_alpha ≤ U_alpha\`, \`L_alpha ↑\`, \`U_alpha ↓\` при возрастании α. Это **дискретная ограниченная конструкция α-сечений**, а НЕ универсальное обучение полного T3-FLS с полноценной процедурой type reduction Karnik–Mendel. Сохранять ВСЕ α-плоскости в объяснении; не схлопывать их в одну расширенную Type-2 полосу и не заявлять новый метод редукции типа.
- Каждая неопределённость снабжена происхождением: \`delta2\` определяется по TRAIN self-supervised оценкам масочного восстановления; \`delta3\` разрешается использовать только при наличии заранее зарезервированной *независимой внешней калибровочной опоры* для минимум двух сред. Разность средних самого источника между средами НЕ подтверждает изменение приборной калибровки: это может быть физический сдвиг.
- Адаптивное решение T1/T2/T3 принимается **только по TRAIN**, по заранее заданным порогам \`d2>0.08\` и \`d3>0.08\` (на нормализованной шкале), при минимум 2 проверенных калибровочных условиях; иначе предпочитать более простой уровень. Сравнить также принудительное применение T1/T2/T3 на одинаковой части данных. Если Type-3 превращается только в более широкий Type-2 без дополнительных практических свойств, признать это отрицательным результатом.

## Условный flow matching

Отдельная маленькая условная модель flow matching на одном скалярном латентном измерительном источнике, **не вместо Transformer**:
- Базовый источник \`a_full\`: оценка амплитуды по TRAIN-наблюдениям и фиксированному TRAIN-only шаблону, НЕ синтетический oracle \`a_true\`; попытаться искусственно скрыть часть имеющихся наблюдений \`m_cond ⊆ m_train\`.
- Условие \`c=(a_cond, observed_information, early_count, late_count)\` вычисляется только из оставшихся наблюдений.
- Регрессировать векторное поле \`v_theta(a_t,t,c)\` для прямого условного потока \`a_t=(1-t)*epsilon+t*a_full\`, target \`a_full-epsilon\`; без outcome меток, TEST, скрытых истинных факторов. Результат — много сэмплов возможной амплитуды и эмпирическая неопределённость, не «истинный байесовский posterior».
- Сравнить point WLS с FlowMean, Type1/2/3 на **одних и тех же** сэмплах и обученных исходных концептах. Сырые видимые значения не заменять генеративными сэмплами; хранить флаг \`observed\` vs \`inferred\`.
- При полном отсутствии всех датчиков источника обе ветви отказывают в новом концепте, несмотря на то, что flow может генерировать правдоподобные образцы.

## Источники данных и проверка

Оставить native двухконцептный Temporal ConceptFAN как **реальную обучаемую Transformer-модель**, а не синтетический линейный суррогат: первая стадия учит K2 только по observed proxy датчиков0–3, без градиентов исхода и скрытых состояний генератора; заморозить, fit K2 голову только TRAIN-метками. Независимо формировать дополнительные временные источники по TRAIN-only измерениям и маскам; сохранять group sensor IDs, temporal template, выбранную шкалу, alpha planes и все коэффициенты риска. Риск нового концепта — отдельное точное аддитивное слагаемое; исходный K2 должен оставаться битово неизменным при добавлении/отказе.

**Данные:** свежий draw из двух доступных и уже реализованных семейств (не внешняя клиника):
- не-AR pulse-order из V31/V33: генератор seed **20261126**, TRAIN1200, две VALID400+400, TEST600, временные ряды16×12;
- независимое семейство nonlinear switching/shock V30: seed **20261127**, те же размеры TRAIN/VALID/TEST, данные16×12.
Три native K2 initialization seeds **11,23,37**, 10 эпох (меньше, чем V33; это новая отдельная программа и все методы используют те же самые K2). Маски TRAIN MCAR20; TEST: complete, MCAR20, MCAR40, block8 *независимый между датчиками*, synchronized_block8 всех source4..6 и full source outage. Также TEST-only sign flip 4..6 (неизвестный на VALID) и VALID+TEST sign flip (известный риск). VALID2 benign drift по группе unknown channels, если калибровочный внешний anchor отдельно подтверждён; запрещено использовать TRAIN/VALID исходы для определения неопределённости границы.
У каждого семейства собственные TRAIN-only группировки и нормировки; запрещено переносить истинные скрытые source group IDs из генератора в поисковик. Для signed sensor sign flip можно использовать метаданные генератора ТОЛЬКО для построения искусственного контрэксперимента, не для выбора/допуска.

**Контроль справедливости и исходных данных:** у всех методов на каждом семействе те же размеченные TRAIN1200 + VALID400+400, но обычные логистические модели могут использовать всю совокупность 2000 случаев для fit; наш source-gate использует последние 800 лишь для выбора источника. Сравнить K2, V32 WLS + линейный head, FlowMean+линейный, Type1, IT2, restricted IT3, AUTO order, raw temporal logistic (TRAIN-only и all2000), all-source ordinary CBM (TRAIN-only и all2000). Не говорить, что compute/FLOPs и label allocation идентичны; не говорить, что скопированы оригинальные CIBM/Res-SCBM и CSDI.

**Метрики**: TEST AUPRC/AUROC/NLL/Brier, source usage/abstention; эмпирическая доля попадания pseudo-truth \`a_full\` в flow interval на **отложенной TRAIN** с искусственным пропуском (не клиническая или latent-truth калибровка); соблюдение α-вложенности, T3 eligibility без внешнего anchor и exact additive logit; влияние false/source sign flips; сохранность K2 SHA; 399 paired TEST-subject bootstrap ΔAUPRC для AUTO−T1 и AUTO−V32 в основных сценариях, с указанием общей тестовой выборки и условности по 3 fitted NN.

**Научные границы**: Type-3 fuzzy sets и α-сечения известны, условные диффузионные методы CSDI (2021), Flow Matching (Lipman et al., ICLR2023), модель Concept Bottleneck и GAM известны. Здесь проверяется новая конкретная интеграция и ablation, а не новая теорема. В случае отсутствия подтверждённого сигнала в новом канале никакая T3/diffusion конструкция не исправляет неидентифицируемость. Semantics: автоматически выделенная группа датчиков ≠ физический/клинический концепт.
