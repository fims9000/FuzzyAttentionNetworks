# ConceptFAN V58: real-data transfer audit on PhysioNet BIDMC
**Registered on 13 November 2026 before new real-data TEST processing.**
Research branch `experiment/conceptfan-v58-real-bidmc-20261113`. Source: PhysioNet BIDMC PPG and Respiration Dataset v1.0.0, DOI [10.13026/C2208R](https://doi.org/10.13026/C2208R), Pimentel et al., IEEE TBME 2017. Data license ODC-BY 1.0. Do not redistribute raw clinical recordings or patient identifiers.

## Goal
V53–V57 were validated on one synthetic generative family. Challenge *native FAN and unsupervised concept generation* on **real measured** PPG-derived monitor PULSE, impedance-derived RESP, and pulse-oximeter SpO2, using a distinct ECG-derived monitor HR as held-out outcome/reference. Unlike V56/V57 synthetic tests, the same ECG HR supplies BOTH the binary outcome and numeric comparison target: it **cannot certify independent measurement corroboration of a concept**. Thus the V56/V57 external-assay gate is NOT applied and no physical meaning is assigned to discovered sensor pairs.

## Predeclared data and partition
- Download **all 53** official `bidmc_##_Numerics.csv` and `bidmc_##_Fix.txt` directly from PhysioNet; verify official SHA256 manifest if provided, retain per-file SHA256 receipts and exact source DOI; no raw waveforms or demographics are used or committed.
- Parse true patient group from `MIMIC II matched wdb ID` in Fix; require nonempty values, group all recordings with the same ID. Patient IDs do not appear in public artifacts: publish only official BIDMC recording ordinal IDs (which are already public), never raw or reversibly hashed MIMIC patient IDs. Refuse if duplicate patients are split. When patient ID unavailable => hard fail, not use record ID as substitute.
- Stable deterministic group allocation with NumPy seed **20265813**: 60% groups TRAIN, 14% VALID1, 14% VALID2, remaining TEST, with minimum six groups per VAL and TEST. No HR-based stratification or cherry-picking. `group_split_manifest.json` stores counts and public BIDMC recording ordinals by group/split, but no original or hashed MIMIC patient ID. TEST groups are **never used for normalization, model fitting, candidate acceptance or threshold setting**.
- 16-step windows of 1Hz numerics, stride **8 seconds**. Each window is an observation, but adjacent windows from one patient are strongly dependent. The label is ECG-derived **HR >= 100 beats/minute**, using mean of the last four 1Hz HR points only if ≥3 are valid. This is a contemporaneous monitor-threshold research task, **not an early-warning forecast or clinical diagnosis**. A true binary class missing in TRAIN or TEST means report the not-estimable result and preserve the split unchanged.
- All sensor channels are derived only from present or **past** PPG PULSE, impedance RESP, SpO2. K2 has 4 channels: current PULSE, RESP, SpO2, PULSE minus RESP. Six potential new observed operators: first differences of each original channel, 3-step trailing volatility for each. Each feature has a strict availability mask and is standardized using TRAIN observed cells only; no ECG HR in any input or feature normalization. No shifted/delayed copy of ECG or target; no intentionally constructed delayed copies to make V54 pass. Device-specific monitor numerics are derived from primary waveforms by unknown algorithms, so no independence/semantic-source guarantee.
- Handle natural NaN as unavailable; do not convert to observed zero. No other imputation than zero placeholder with availability mask. Frozen scaling mean/std with floor .1. Keep finite values.

## Fixed model/controls
- K2: existing native temporal PyTorch ConceptFAN with fixed initializations **11,23**, 5 epochs; risk bottleneck has no raw-to-risk shortcut.
- Discover V54 SIGNED_LAG and EVEN_ENERGY_LAG from TRAIN X only using original *unaltered* min fold corr .65 and improvement ≥.30 over same-time corr, lags 1–3; max three disjoint pairs. This stringent synthetic-designed gate may produce **zero candidates**. Do **not** lower it after observing TEST and do **not** fabricate new concept evidence.
- For each candidate, fit V55 constrained mixture+gamma using TRAIN Y; admit at most one only if it independently passes the existing dual-VALID V28 predictive NLL/support criterion. If none admitted => prediction exactly frozen K2, with an explicit refusal reason and zero proposed source usage. No TEST labels in proposals or selection.
- Equal-TRAIN-label baselines: logreg on K2 channels, logreg on all engineered channels, PULSE-only logreg, and the direct PULSE monitor score. The direct PULSE score is not a calibrated NLL baseline.
- TEST conditions are predeclared: (a) natural missingness, (b) additionally MCAR20 on input channels, (c) missing PULSE entirely, (d) PULSE +25 bpm bias applied coherently to input monitor values before re-computing derived features. No ECG HR perturbation. No refitting after testing.
- Primary outcomes: real TEST AUPRC, NLL, precision-recall of ECG HR>=100, number of automatically proposed/accepted operator definitions; direct PULSE-versus-ECG absolute error; unchanged K2 fallback; patient-group macro error and uncertainty. Label-balanced metrics may be **not estimable** if TEST has one class. Report patient-group counts, subgroup prevalence and 95% bootstrap confidence bands by TEST **patients**, never by overlapping windows.
- Independent source audit: reload held-out per-window arrays (for all stress×seed), re-evaluate metrics and verify checksum, native signed decomposition and bitwise K2 fallback where no source. Keep *only aggregated or pseudonymous patient-group metadata* in artifacts; exclude individual vital signs and raw observations. The audit may process individual arrays transiently in GitHub Actions but upload only aggregate report, hashes, and group-level summaries (not patient-level raw predictions).

## Falsification and boundaries
1. If no V54 concept is found on genuine real measurements, record **negative result**, do not adjust operator gain or invent shifted channels.
2. If a concept is admitted but hurts TEST metrics vs K2 or strong engineered baseline, report negative result. All data originate from the same BIDMC ICU cohort; no new clinical site.
3. ECG HR is BOTH TEST scoring reference and the supervised binary label: the reference cannot be presented as an independent physical assay of the newly learned concept. `RESP` also comes from a monitor, not necessarily clinician-interpretable physiology.
4. Consecutive windows overlap in time and patient recording. Train/VAL/TEST are by genuine MIMIC patient group; any window-level bootstrap falsely inflates sample size.
5. No claims of certified concept names, medical utility, patient-level clinical risk prediction, causal discovery, generalized measurement provenance, or superiority to established PPG peak algorithms. This is a **real-world failure/success audit of measured-feature FAN architecture**, not a clinical trial.
