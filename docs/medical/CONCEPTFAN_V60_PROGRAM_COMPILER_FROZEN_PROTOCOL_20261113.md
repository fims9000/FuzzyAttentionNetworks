# ConceptFAN V60 — Global redesign: Program Compiler + Sparse Native Concept Risk

**Research protocol frozen 13 Nov 2026 before running any V60 outcomes.** New branch `experiment/conceptfan-v60-program-compiler-20261113`. No changes to previously audited V53–V59 scripts or headline numbers. This is a **new competing architecture**, not a retrospective re-labeling of V54's failure. The same BIDMC/VitalDB datasets were already inspected in V58/V59: V60 tests are **exploratory comparisons**, NOT an untouched confirmatory external-site test.

## Parent architecture objective
Remove V54's fundamental dependence on lagged association beating contemporaneous correlation, and replace fixed K2 concept definitions with **measured, typed, composable programs**. The complete path:
1. Compile finite, human-readable, **causal** measurement programs from named channels, using no target Y.
2. Screen TRAIN subject-folds only for observed support, nonconstant variation and redundancy; do **not** require hidden generators or a special lag signature.
3. Normalize each accepted program on TRAIN observed windows only (robust TRAIN median and IQR); values for missing programs are exactly neutral.
4. Jointly learn **bounded program calibrations** and a sparse *signed additive concept-only* native PyTorch risk head using TRAIN Y. Include both **pure compiled concept head** (replaces K2) and **K2-residual head** (extends frozen K2).
5. Evaluate both unconditionally and with a fail-closed, dual-VALID, **patient-cluster rather than overlapping-window** admission check. The chosen model must demonstrably improve VALID1 and VALID2 over frozen K2; if not, used prediction is **bitwise exact K2**. The entire vector of new source coefficients is the admitted program, not a physical concept certificate.
6. Save each source passport (operator, channel IDs, TRAIN median/IQR, support, gamma, calibration), signed per-program contributions, ablations and transparent refusal reasons. No raw-to-risk shortcut: `logit = frozen baseline + sum_k gamma_k*(q_k−.5)`. The pure variant's baseline is a constant TRAIN-label prior, also through a concept-only head. Both are testable within a native torch module.

## Fixed outcome-blind program grammar
Only actual original three inputs `PULSE, RESP, SpO2` may be operands, not HR, outcome, simulator factor or redundant pre-engineered columns. Build all:
- For each of 3: `LEVEL_LAST4` (mean last4), `LEVEL_16` (mean all16), `TREND_8` (last4 minus prior4), `VOLATILITY_8` (std last8), `ENERGY_8` (mean squared centered changes over last8), `HIGH_EVENT_8` (fraction of last8 above TRAIN 75th percentile). All with strict masks and no look-ahead.
- Each of 3 unordered pairs: `CONTRAST_4` (mean of TRAIN-normalized signed pair differences, observed same t) and `COACTIVITY_8` (simultaneously above each sensor's TRAIN median). These are **observed programs**, not proved physical relations.
- Total **24** expression candidates (18 unary + 6 pair). Never generate from outcome labels, HR, future target window or hospital site.
- Fixed TRAIN subject-fold screen: at least 3 distinct TRAIN subject groups with minimum 50% program availability and foldwise nonconstant dispersion; missing subject coverage <50% is a refusal. Rank redundancy by TRAIN (absolute Pearson) > .995 and retain the earlier lexicographic program. Maximum 24. If none, return K2.
- Normalize TRAIN **observed episode values** by TRAIN median and IQR, floor .1; robust raw sensor q75 and medians are TRAIN-only. The last4/last8 programs use no future samples; missing episode membership neutral q=.5; low coverage means zero additive source contribution.
- No independence or physiological/causal meaning follows from temporal support, consistency or risk gain. Presence of PULSE level as a program means this method may be effectively equivalent to ordinary logistic regression; report that equivalence explicitly rather than claiming a new mathematical discovery.

## Fixed native predictor and fit
`q_j=0.5 + support_j * [sigmoid(alpha_j*(v_j−TRAIN_median_j)/TRAIN_IQR_j−offset_j)−0.5]`, alpha in [0.5,3], offset in [−2,2]. Gate episode support >= .5 for each source. `z=b+sum_j gamma_j*(q_j−.5)`. For K2-residual `b=frozen native K2 logit`; for pure replacement `b=TRAIN prior log-odds`. Learned parameters: alpha/offset/gamma only; **never** inputs directly in risk. 220 full-batch steps Adam lr .035, mean logistic loss with each TRAIN patient given equal total sample weight; regularization `0.0025 sum_j sqrt(gamma_j²+1e−6) +0.01 mean((alpha−1)²)+0.005 mean(offset²)`, no tuning on VALID/TEST. At most 6 sources retained after training ranked by |gamma|; **refit only gamma on TRAIN** after source pruning for 80 Adam steps with other parameters frozen. Freeze all at admission.
- Compare `K2`, pure `PROGRAM_FAN`, `K2+PROGRAM_FAN`, `dual_VALID_selected_or_exact_K2`, BIDMC-only raw logistic, engineered logistic, and PULSE-only logistic. No multiple-hypothesis rejection based on TEST results.
- Admission of full **model**, not a single source, on both VALID1/VALID2: choose the better of pure/residual using **TRAIN-only patient-macro NLL** after regularized fitting (no VALID1 selection and no TEST), then require: at least 4 independent groups per VALID, patient-macro NLL gain >=.005 on each, 99% one-sided **whole-patient** bootstrap lower bound >0 on each with 399 reps, and source episode coverage >=.50 in each VALID. If fails, exact frozen K2. This patient-cluster criterion is intentionally stricter than V28's prior window bootstrap; likely may reject all with only 6 patients per environment. Do not relax after viewing data. Report proposed model separately from deployed admitted model.

## Falsification criteria
- On real BIDMC, at least one program should pass **outcome-blind** TRAIN screen for this feature grammar; zero would reveal a compiler bug/missingness problem. More programs does **not** imply improved prediction.
- Native pure ProgramFAN should be compared to strong PULSE-only and logistic baselines. If its TEST AUPRC/NLL are worse or dual-VALID rejects, report failure without adjusting thresholds after TEST.
- No physical semantic certificate: same-time monitor PULSE is strongly correlated with contemporaneous HR, and even future 60-second HR labels do not prove identifiable causal physical concepts. Without independent reference device provenance one cannot claim medical meaning, physiological discovery or clinical use.
- The two previously inspected hospitals are exploratory, NOT an independent confirmatory validation after architecture development. Use a fresh hospital/device source for later confirmatory claims, not these datasets again.
