# ConceptFAN V61R — posthoc numerical-stability repair of conditional source research

**Methodological amendment dated 13 November 2026, written AFTER seeing V61 BIDMC/VitalDB outcomes. NOT preregistered, NOT confirmatory.** Parent [V61 draft PR #73](https://github.com/fims9000/FuzzyAttentionNetworks/pull/73). Original V61 negative results, source hashes, gates, and reported test outcomes MUST remain unchanged and archived. New branch \`experiment/conceptfan-v61r-stable-sources-20261113\` forks V61 and changes training/source definition stability *only* for a new exploratory engineering reproducibility experiment. Historical results from V61/V60 must not be overwritten.

## Why V61 requires this repair
The V61 program risk head used the V60 code path: its seed was set but trainable alpha, offsets and gamma all had **identical fixed initial values**. Consequently V61 seeds 11 and 23 produced **identical trained heads**, not two independent random inits. Replaying the original BIDMC benchmark in separate CI workflows also exposed a pronounced sparse-selector instability: roundoff-size differences in the label-blind TRAIN-only Ridge residualizer (typically 1e−14) changed which of 12 correlated HR residual programs survived V60's task-trained top-six gamma selection, creating large changes in prediction even though the same real patient split and same program-bank passports were used. All V61 deployment decisions still **refused** additional sources on both validation groups, so this instability did not invalidate the exact PULSE-only deployed fallback, but did invalidate claims of stable speculative ungated source predictions.

## Repair (fixed before new V61R fitting/execution)
1. Freeze independent-source definitions using only **TRAIN observed input X**, not outcome gamma:
   - start from V61 label-free Ridge residuals on allowed non-PULSE channels;
   - select at most **six** conditional source programs using deterministic TRAIN-only support/stability/low-redundancy criteria;
   - prioritize distinct original non-PULSE sensor groups and statistically stable conditional residual variation, then fill remaining slots by measured TRAIN-fold stability; forbid any program reading PULSE directly or future RESP target;
   - the list of ≤6 active *candidate* definitions and its ordered IDs must be part of the model passport. The selection cannot look at patient TRAIN Y, VALID Y, TEST or a model's previous win/loss.
2. Canonicalize the TRAIN-only Ridge residualizer numerically: round fitted input-source coefficient and intercept to **12 decimal places**, calculate and round TRAIN residual median/IQR to 12 decimals. Quantized values are the **exact** values used for TRAIN and inference. This removes machine-order sensitivity from source definitions, but does not manufacture conditional independence.
3. Keep the native V60 concept-only signed network, but add optional parameters with **unchanged defaults for V60/V61**:
   - \`train_initialization_std=0.03\` gives actually different seeded stochastic initial values of alpha/offset/gamma for the V61R head (two fixed seeds 11/23);
   - \`retain_all_predeclared_sources=True\` stops the brittle top-6, signed-gamma threshold **selection** after the original outcome-blind source shortlist. All six programs may carry a zero/weak signed effect; fitted risk components remain fully inspectable. The original gamma shrinkage / refit and TRAIN-only optimization stay.
4. Pin CPU deterministic Torch operations, one Torch thread, and explicit source tensor dimensions. Record checksums of canonical TRAIN source shortlist, numerical operator/refit passport, and result arrays. Require deterministic **source identities** across two independent workflow runs, and report if weights/predictions differ beyond a predeclared numerical tolerance (max |logit difference| 1e−4 on matched heldout cases). If it fails, report \`REPRODUCIBILITY_FAILURE\`, do not claim stability or deploy.
5. Retain the original V61 strict group-bootstrap +49 within-person PULSE-stratified null gate without any threshold adjustments. A refused model returns **bitwise exact original PULSE-only head**. Do not promote speculative ungated results posthoc.
6. BIDMC original 53 records / patients and frozen VitalDB 40 patients are **previously inspected**. All results of this repair are engineering **sensitivity analysis**. The same +60s future HR≥100 and RESP≥20 with RESP hard-excluded from input are kept. Same strong pulse/full-feature logistic baselines, same four sensor stresses; no hyperparameter, task, population or outcome selection from TEST.

## Stop conditions and what can be claimed
- If source selection still differs between two truly independent CI executions, or actual seed initialization still produces identical heads, the reproducibility issue remains unsolved.
- If non-PULSE sources continue to fail two VALID patient groups and conditional null, the scientific novel-source question remains **negative**, independently of a better training stability report.
- Physical sensor identity, independent source causality, general medical usefulness, stronger ranking than a pulse-only monitor classifier, and heldout confirmatory evidence are **not** established by any V61R experiment.
