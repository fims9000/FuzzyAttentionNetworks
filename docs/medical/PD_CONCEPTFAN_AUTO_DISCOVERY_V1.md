# PD-ConceptFAN v1: автоматическое обнаружение динамических концептов

**Статус:** новая проверяемая исследовательская гипотеза, отдельно от принятых
результатов PIERE и исправлений PR #2. Это **не** клиническая система.

## 1. Что было неправильно сформулировано в прошлой работе

В Med-CircuitBench пять латентных состояний задаются генератором и являются
обучающими целями; в PhysioNet вручную заданы пять медицинских групп с
перечнями измерений и правилами агрегации. Поэтому старое исследование
проверяет **устойчивость известных названных концептов**, а не их
самостоятельное открытие из ряда. В Anchor-подходе значения общих центров,
масштабов и коэффициентов тоже получаются из заранее заданных концептов.

Здесь удалена **вся concept-label supervision**. Нейросеть получает только
прошлые измерения, маску доступности, исход и **будущие наблюдаемые
измерения**. Истинные скрытые состояния генератора загружаются исключительно
в поздний аудитор соответствия; они никогда не передаются модели или функции
потерь. В пользовательском реальном датасете они вообще не нужны.

## 2. Откуда концепт берётся математически, а не словесно

Пусть (X_{1:T}\in\mathbb R^{T\times 8}) — наблюдённые физиологические
сигналы; (M_{1:T}\in\{0,1\}^{T\times 8}) — наблюдаемость.

Только по **train** считаются медиа́ны (m_j) и межквартильные диапазоны
(s_j), и значения стандартизируются как
(z_{tj}=\mathrm{clip}((x_{tj}-m_j)/s_j,-6,6)).

Из каждого канала строятся фиксированные **каузальные в смысле времени**
(не причинные медицинские!) операции:

- текущий уровень (\tanh(z_{tj}/2));
- средний уровень за четыре последних наблюдаемых часа;
- изменение за один час при наличии обеих точек;
- отклонение от последнего четырёхчасового среднего.

Каждая операция доступна в обоих направлениях. В результате (D=8\times
4\times2=64) прозрачных измеримых признака (phi_j(X_{\leq t})). При
отсутствии исходного измерения соответствующие операции помечаются
ненаблюдаемыми; на абсолютные нули отсутствующих значений нет обучаемого
непрозрачного преобразования.

Для каждого из **максимум 10 слотов** сеть обучает собственное определение:

[
W_k=\mathrm{sparsemax}(\omega_k),\quad W_{kj}\geq0,\quad\sum_jW_{kj}=1.
]

Значения с (W_{kj}=0) действительно удалены из формулы (не только
"малые веса" на карте внимания). Взвешенный сигнал корректируется на долю
доступных измерений (r_{tk}\in[0,1]):

[
q_{tk}={\sum_jW_{kj}\phi_j(X_{\leq t})\over\max(r_{tk},0.2)},\qquad
c_{tk}=g_k\,r_{tk}\,
\sigma\left({q_{tk}-\tau_k\over \delta_k}\right).
]

- (\tau_k\in[-1,1]) — обучаемая **граница** срабатывания в шкале
  составного признака;
- (\delta_k\geq0.08) — обучаемая **ширина** нечёткого перехода;
- (g_k\in[0,1]) — обучаемая активность слота;
- (W_k) — точный список использованных измерений, операторов и
  направлений. Это определение концепта, а не последующий пост-hoc
  анализ готовой сети.

Если концепт почти целиком основан на уровне одного измерения, границу
можно приближённо перевести обратно в исходные физические единицы.
**Если участвуют несколько измерений и операций, одного честного порога
давления, креатинина и т.п. не существует.** Показывается исходная
составная формула, а не придуманная "клиническая норма".

## 3. Почему число концептов не равно пяти по умолчанию

(K_{\max}=10) — исключительно верхнее ограничение памяти и поиска, а не
предположение о существовании десяти смысловых сущностей. Для каждого слота
используем hard-concrete gate и приближение к L0:

[
\mathcal L_{\rm MDL}\propto\sum_k\Pr(g_k\neq0).
]

Функция потерь одновременно штрафует сложность определений (sum_j\sqrt{
W_{kj}+\epsilon}) и дублирование *определений* (W_k^TW_l). Мы не
заставляем реальные физиологические процессы быть ортогональными.

В отчёте честно различаются:
1) ожидаемое число ненулевых gates в релаксированной модели;
2) число gates выше порога 0.5;
3) число действительно меняющихся с пациентом/временем активных слотов;
4) точность сети после фактического жёсткого отсечения слотов.

**Эффективный K — операциональная оценка по выбранному критерию, а не
теорема о количестве истинных скрытых факторов.** Если все десять слотов
остались активными, автоматическая минимальность не достигнута — это
отрицательный результат, который необходимо сохранить.

## 4. Концепты являются частью РЕШЕНИЯ, а не post-hoc украшением

Каждый концепт имеет временную траекторию (c_{1:T,k}).
Наблюдаемая активность и длительность события определяются из неё
порогом 0.5 и минимальной длиной события 2 часа; порог и длина указаны в
протоколе и не выбираются для красивой визуализации.

Прогноз класса строится **исключительно через** концептное пространство:

[
\ell(X)=b+\sum_{k=1}^{K_{\max}}\beta_k
\left(\frac16\sum_{t=T-5}^{T}c_{tk}-\frac12g_k\right),
\qquad \hat P(Y=1|X)=\sigma(\ell(X)).
]

Здесь (\beta_k=3\tanh(\tilde\beta_k)) ограничены. Никакой
дополнительной ветки из исходного ряда прямо к классификатору нет.

Поэтому изменение одного концепта при фиксированных остальных даёт
**точное** изменение логита:

[
\Delta\ell_k=\beta_k(\bar c'_k-\bar c_k).
]

Это доказуемое свойство программной модели, **не** доказательство того,
что изменение медицинского механизма причинно изменит смертность.

## 5. Предиктивная динамика как внешний критерий качества понятий

Одной метки Y может быть достаточно для одномерной статистики
(c(X)=P(Y|X)); таким способом нельзя обосновать биологический смысл
дополнительных осей. Поэтому предсказательная задача дополнена
**прогнозированием наблюдений** в следующих шести часах с того же
концептного состояния:

[
\hat C_{t+1}=g\odot[0.7C_t+0.3\sigma(AC_t+d)],\qquad
\hat X_{T+h}=DC_{T+h}+a.
]

Динамика обучается регуляризатором на
(\|\hat C_{t+1}-C_{t+1}\|), разреженным (A) (штрафуются
внедиагональные элементы) и наблюдаемым future loss. **Будущие X
используются только как обучающая цель; они не поступают во вход
концептного энкодера.** Структура переходов является модельным
приближением, а не идентифицированной причинной системой.

Полная формула:

[
\mathcal L=\mathcal L_Y+
\lambda_f\mathcal L_{\rm future}+
\lambda_d\mathcal L_{\rm dynamics}+
\lambda_K\mathbb E\|g\|_0+
\lambda_s\mathcal L_{\rm operators}+
\lambda_r\mathcal L_{\rm redundant}+
\lambda_v\mathcal L_{\rm nonconstant}+
\lambda_A\|A_{\rm offdiag}\|_1.
]

`task_only` — лишь классификация (полный резерв слотов, нет динамики и
MDL), `task_future` — классификация и будущие измерения, `full` —
полная формула. Нужны все три абляции: повышение согласованности от
фиксированной базы может быть тривиальным.

## 6. Как увидеть конкретный концепт и пациента

Для каждого обученного слота автоматически сохраняется **паспорт**:
- подписанные операторы, их ненулевые веса;
- граница (\tau_k), ширина (\delta_k), активный gate (g_k);
- доля наблюдаемых источников, время начала/окончания эпизодов;
- доля пациентов с событиями, длительность активации;
- фактический вклад концепта в логит конкретного пациента;
- эффект искусственного зануления прямого вклада для AUPRC;
- когда честно допустимо — приблизительный порог в физических единицах.

Индивидуальные концепты каждой модели хранятся вместе с checkpoint,
config SHA-256 и независимой квитанцией о том, что test не использован.

## 7. Как исключается ложная "статистическая устойчивость"

Слоты разных обучений допускают перестановки. Нельзя измерять
согласованность по сырым индексам (k\) (у одной модели Concept 1
может быть Concept 7 у другой).

Сопоставление слотов выполняется Hungarian assignment **по их обученным
операторным определениям**; не по исходам и не по тестовым пациентам.
Отдельно оцениваются:
- устойчивость самих определений и штраф за непарные слоты;
- корреляция реакций сопоставленных концептов между пациентами;
- согласованность *конкретно соответствующих пациентов*;
- превышение согласованности над контролем, где эпизоды переставлены
  независимо: глобально одинаковый rank всех концептов у всех пациентов
  **не** считается содержательным успехом.

В пилоте четыре seed инициализации × два seed порядка данных. Все пары
связаны общими моделями, поэтому модельный bootstrap показывается только
как чувствительность, **не как статистическое доказательство**.

## 8. Честные границы интерпретации и новизны

Метод всё равно использует инженерно выбранный класс математических
операций. **Человек исключён из разметки конкретных концептов, а не из
формулировки гипотез и измеримых индуктивных ограничений.**

До доказательства на реальных данных нельзя называть обнаруженные оси
"почечной дисфункцией" или "сепсисом" без внешней проверки специалистом.
Истинные пять состояний Med-CircuitBench используются исключительно для
ретроспективной проверки соответствия найденных факторов механизму
генератора, а не для их обучения.

Существенный аналог: MAGNETS (Forest, Wei, Fink, 2026) уже обучает
неразмеченные концепты и явную временную локализацию для временных рядов.
Поэтому **автоматическое concept discovery само по себе не ново**:
https://doi.org/10.1007/s10618-026-01267-y

Отличие, которое здесь **пытаемся проверить**, а не заявляем как
установленный приоритет: совместная причинная по времени библиотека
операторов, отбор числа слотов, простой предиктивный закон переходов,
прогноз измерений, честный паспорт и независимая seed-устойчивость с
проверкой нетривиальности.

## 9. Воспроизведение

```bash
PYTHONPATH=src:. python -m pytest tests/discovery -q
PYTHONPATH=src:. python scripts/medical/run_predictive_dynamics_discovery.py \
  --config configs/medical/predictive_dynamics_discovery_v1.yaml \
  --out-dir artifacts/medical/discovery_v1_trainval_01
```

GitHub Actions: `.github/workflows/discover-dynamic-concepts.yml`.

Результаты: `summary.json`, `per_run_metrics.csv`,
`pairwise_definition_matched_stability.csv`, `provenance.json`,
`train_validation_only_receipt.json`, checkpoints и
`operator_concepts.json` для каждого запуска.

Нельзя объявлять научный успех, если сокращение числа слотов не произошло,
объяснения не отличаются между пациентами или существенная часть AUPRC
потеряна. Новые результаты не заменяют отрицательный результат исходной
статьи PIERE.

**После пилота:** новая замороженная синтетическая репликация на двух-трёх
других генераторах с разным истинным числом факторов, затем новый
отдельный train/validation-проект PhysioNet без фиксированных пяти
целевых прокси; только после этого допускается заранее определённый
однократный test. Старый test не используется для подбора параметров.
