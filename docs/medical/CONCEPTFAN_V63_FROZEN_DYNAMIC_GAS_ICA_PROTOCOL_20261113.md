# V63 preregistration — blind source separation on previously unused real dynamic gas mixtures

**Registered 13 November 2026 before reading ANY UCI 322 data values or held-out source labels.** V60–V62 were evaluated on different UCI data (IDs 360 and 309); UCI ID **322** has not been inspected. V63's proposed algorithm arises from the V62 failure, so even a positive result is exploratory across data families, not a fully independent scientific hypothesis preregistration. Full archive schema checks may adapt parsing only, never outcomes, K, or thresholds.

## External physical intervention

UCI [Gas sensor array under dynamic gas mixtures](https://archive.ics.uci.edu/dataset/322/gas%2Bsensor%2Barray%2Bunder%2Bdynamic%2Bgas%2Bmixtures), DOI **10.24432/C5WP4C**, 16 raw sensor outputs in two continuous ~12h recordings, ethylene+CO and ethylene+methane, independently programmable concentration setpoints. Published sample rate ~100Hz. Original 19 columns: time, secondary-gas setpoint, ethylene setpoint, 16 measured sensor outputs. Only columns 3–18 enter input representation, normalization, source identification and self-supervised training; time used for grouping and chronological split; columns 1–2 are *never observed* by source discovery/encoder. **Setpoints are controller commands, not independently sampled gas concentration ground truth**. No device-fault labels and only two independent recording sessions: do not present 100s or thousands of derived windows as independent experimental sessions.

## Locked data reduction and boundaries

- Read the original official archive with intact source SHA256 and exactly two named text files; fail on duplicate/missing/non-finite source values. Parse streaming in bounded memory; aggregate **1-second sensor medians and 1-second setpoint medians** by true time bin, not row index; refuse seconds with fewer than 20 sensor samples. Do not interpolate or deduplicate missing chunks. Preserve absolute seconds and source recording IDs for grouping; aggregate-only artifacts without raw individual rows.
- Per recording, chronological FIRST **60%** seconds TRAIN, NEXT **20%** VALID, LAST **20%** TEST, with **120-second embargo** on BOTH sides of boundaries, set in time before any signal labels are read by any method. Select disjoint **120-second windows** within each split and require complete, consecutive one-second bins. The windows are correlated because each file is one ~12h session; report this in every metric.
- Each selected window is one sequence [120,16]. Sensor median/IQR scaling is fit on **TRAIN only**; clip standardized signals to [-8,8]. Train-only source formation takes no controller setpoints or supervised targets. VALID is never used to train source axes or supervised regression coefficients; used only for post-hoc association/naming audit. TEST must be untouched until both source definitions and all task coefficients are fixed.
- Three reference outcomes evaluated: ethylene ppm on CO recording, ethylene ppm on methane recording, and CO or methane ppm on its relevant recording. Use mean of controller setpoints during window seconds 90–119; 120s window history includes those sensor readings. This is **contemporaneous concentration estimation**, *not* future-hour prediction or direct concentration assay. For all target regressions, TRAIN and TEST are distinct chronologically embargoed blocks from the same recording.

## Frozen V63 source-discovery mechanism: unsupervised sensor innovations + ICA

- For each unlabeled TRAIN window derive a 16-dimensional innovation, delta = median(last 30 s sensor readings) minus median(first 30 s sensor readings). Fit a separate shared 16-channel sensor normalization on complete TRAIN observed measurements (no setpoints). Use **TRAIN innovations only** to fit PCA rank; choose the MINIMUM K achieving >=**95%** explained innovation variance, bounded to [1,8], and report the unclipped rank and all explained-variance ratios. K is NOT supplied as the real number of gas species. In particular K may exceed 2 or equal 1.
- **FastICA** on standardized TRAIN innovation vectors, fixed seed **20261913**, max_iter=1000, tolerance=1e-4, whiten=unit-variance, n_components=K; no exposure-gas labels in ICA. Convert the learned ICA sensor projection to fixed [16,K] directions; normalize and canonicalize signs by the largest absolute loading per axis. Contrasting PCA basis with the same K is the rank-matched control; no other hyperparameter search on either VALID or TEST. Nonconvergence is logged and invalidates any strong identification claim.
- Transform each timestep of each 120-step episode using the *same* fixed PCA/ICA sensor loadings, TRAIN means and standard deviations; initialize fuzzy thresholds (TRAIN medians) and positive widths (TRAIN IQR/1.35; min .15) on projected observed TRAIN values only. Hide missing payloads rigorously, no controller commands enter the model. All source axes are anonymous statistical components, not chemically named concepts.
- Train the identical V56 native causal recurrent fuzzy encoder separately for PCA-K and ICA-K on original TRAIN windows only: epochs=8, seed11, 20% randomized source dropout, source denoise/next-step forecast (without setpoints). Freeze network and hash BEFORE supervised heads. Use V55 static fuzzy projection as ablation. Risk regression heads are **Ridge(alpha=1)** from time-averaged fuzzy concept state only to measured concentration setpoints on each training file, for PCA, ICA static/native. Exact raw-to-risk bypass forbidden. This regression is for engineering utility and does not itself validate concept semantics.

## Locked comparison and semantic audit

- Compare rank-matched PCA-K static/native, ICA-K static/native and **raw 16-sensor Ridge**, **raw 16-sensor HistGradientBoostingRegressor(max_iter=100,max_leaf_nodes=15,l2_regularization=1,random_state=0)**. Raw features = observed sensor means from last 30 seconds and whole 120 seconds, with TRAIN-only scaling; no flow setpoint feature.
- Test metrics by recording and target: R², MAE in actual ppm, Spearman and **normalized MAE relative to TRAIN target std**. Report same targets on VALID and TEST. Highlight negative R² / trivial constant baseline.
- Unsupervised physical association: calculate Spearman of each frozen concept's last-30s mean with ethylene and other gas setpoint for each file, all axes, per VALID and TEST; *also* partial Spearman by rank-residualizing on the other gas setpoint, plus pairwise component redundancy, raw sensor correlations and a fixed-shuffle setpoint negative control. No selection of the best axis for decision on TEST.
- A separate **VALID-informed** bipartite max-|partial rho| assignment may give an audit-only tentative concept↔gas map, then TEST evaluate this **fixed** correspondence (including cross-talk). Because this uses gas labels on VALID it is explicitly NOT unsupervised discovery of semantic identities. If K<2, abstain from two-source association. Test correlations are descriptive within continuous recordings, not 100s of independent human/patient samples. Avoid p-values based on independent windows.
- No TRAIN, VALID or TEST setpoint ever goes to `fit_unlabeled` or neural source training. All evidence includes exact source SHA256, splits by seconds, K, bootstrap (TRAIN 30-minute block-bootstrap for rank stability; 20 repetitions), two independent *recording* count, axis alignment ambiguity, and failure outcomes. Quantitative claims are bounded to this physical apparatus and no clinical relevance is asserted.

## Predeclared falsifiers

1. K may be 1 despite two controllable gases; ICA then cannot physically separate them. A 95% PCA variance criterion is NOT chemical-source count.
2. ICA may produce statistically independent coordinates that are mixtures of physical gas inputs; high concentration correlation on one continuous trace cannot prove unique gas identity or causality.
3. If raw predictors outperform concept-only Ridge, record and retain the negative utility result.
4. Two sequences cannot certify independent session/site generalization, calibration independence, sensor-failure recovery, or physiological mechanism identification.
5. No gas concentration trajectory from the controller shall be mislabeled as independent GC-MS verification.
