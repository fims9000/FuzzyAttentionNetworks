# ConceptFAN V22d — frozen **equal labeled-episode budget** control (2026-11-04)

## Predeclared mechanism question
V22b and the frozen unused TEST seed 522203 (V22c) showed large outcome AUPRC gains when 200 independent TRAIN labels were allocated to an external candidate–risk screen that initializes signed native risk coefficients and permanently zeroes independent-screen-rejected concept contributions. But the "arbitrary" V22b arm trained with 600 labels while the screened arm used 600 for native gradients **plus 200 additional TRAIN labels for source-risk selection**. The gains therefore have an important **label-budget allocation confound**. More importantly, V22b's natural baseline is not the strongest approach with the same full 800 outcome labels.

The precise **V22d hypothesis**: compare fixed source axes and original native ConceptFAN under alternative allocation of the **same 800 labeled TRAIN episodes**:
- **joint_800_labels**: fit the identical K2 native model, same V10 supervised task/forecast/masked reconstruction training, ten epochs batch 96, on all 800 TRAIN episodes; no explicit source-task sign screen, no descriptive masks.
- **screened_600_fit_200_gate**: fit on exactly first 600 TRAIN episodes; remaining 200 TRAIN labels used strictly for frozen V22b independent per-concept signed association and native coefficient initialization/serialized no-risk masks; exact same 10 epochs batch 96 for model fit.
- The **TRAIN-only pooled PCA whitened transform and environmental covariance source basis are calculated only on the first 600 source-proposal episodes for BOTH arms**. Hence the extra 200 TRAIN observations do not improve the source covariance estimator in either arm. The source-bearing native input columns, frozen basis, model capacity, loss objective and seeds are identical at initialization.

Both arms consume information from **800 labeled TRAIN episodes** but in *different ways*. The screened arm has 600 native optimization cases plus a 200-case explicitly supervised task-screen procedure. The joint arm has 800 native optimization cases and no separate gate. This is a label-budget-controlled comparison, **not exactly compute/gradient-exposure-matched**: joint model gets 800×10 stochastic updates, screened model only 600×10 but runs 199 permutation + 199 bootstrap risk tests per source. Do not attribute all observed differences to deep network architecture or universal optimizer behavior.

## Metrics and decision interpretation
For every scenario, source method and label-budget allocation arm, mean TEST AUPRC, AUROC, Brier, exact additive logit and source-vs-artifact alignment. Compare both predictive improvement **and calibration**. Include all 3 model seeds on the same TEST 300 episodes and keep per-seed outcomes; no independent-cohort p-value from three seeds.

If screened 600+200 outperforms joint 800 even with fewer native gradient cases, that supports benefit from **explicit task-mediated source screening and interpretive risk control** under these hyperparameters, not novelty of BSS or a proof of semantic correctness. If 800 joint catches or beats 600+200, the earlier gain was less meaningful after controlling label availability; state clearly. Synthetic source identity remains artificial generator truth; no clinician validation or real physical causal interpretation. Source noise could still be an artifact and pass the outcome-risk screen.
