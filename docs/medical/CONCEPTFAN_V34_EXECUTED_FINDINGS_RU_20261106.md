## 1. Что реализовано в архитектуре

Текущий прототип **не заменяет Transformer диффузией**. Исходный native Temporal ConceptFAN имеет свой TransformerEncoder, обучается по наблюдаемым парным прокси каналов 0–3; истинные скрытые синтетические концепты и метки исхода не используются при обучении представлений K2. После этого начальный Transformer и исходная линейная голова K2 фиксируются. Это контролируемая постановка: мы отделяем полезность нового концепта от изменения старых.

Дополнительная группа измерений образуется автоматически по согласованным TRAIN-корреляциям между прежде не назначенными датчиками; её физический смысл в алгоритме **не устанавливается**. Для группы TRAIN-only вычисляется масочный временной шаблон rank1/WLS (V32). По нему маленькая условная модель **rectified flow matching** получает отдельные сэмплы возможной амплитуды нового временного источника. Обучение flow полностью самоконтролируемое: модель пытается восстановить WLS-псевдометку по TRAIN-измерениям, когда часть этих измерений искусственно скрыта. Она **не** обучается на медицинских исходах и **не** восстанавливает истинную скрытую амплитуду генератора по привилегированным данным. Flow — одномерный условный генератор, а не полная диффузионная модель CSDI для всех 12 каналов.

Новому концепту можно поставить один из четырех режимов:
1. **Type-1:** одна степень принадлежности. Никакой неопределённости принадлежности не кодируется.
2. **Interval Type-2:** допустимый интервал степени принадлежности из неопределённости амплитуды, восстановленной по неполным измерениям.
3. **Restricted interval Type-3:** четыре вложенных α-сечения \`{.25,.50,.75,1}\`. У ширины Type-2-интервала есть дополнительная независимая неопределённость *порога определения концепта*, подтверждённая внешним калибровочным эталоном. Проверяется вложенность интервалов и сохраняются обе границы для каждого α. Это **упрощённая α-plane конструкция**, не полная Type-3 система с общим type-reduction.
4. **Auto:** выбирает наиболее простой из доступных порядков на TRAIN при фиксированных порогах. Для Type-3 необходимы два независимо проверенных режима измерительного эталона. Сдвиг распределения самого источника не принимается за изменение калибровки прибора.

Каждый дополнительный концепт формирует отдельное проверяемое слагаемое \`γ*(μ−0.5)\` в логите. Коэффициент γ обучается по TRAIN-меткам; он допускается к прогнозу только при независимом положительном результате на **двух VALID-подвыборках**. Сохраняются точные значения K2-концептов, исходная голова и отсутствие необъявленного сырого обходного пути к Y. При полном отсутствии источника дополнительное слагаемое равно нулю, даже если Flow генерирует образцы: **образец генератора не выдаётся за наблюдение**.

Есть важная граница: **новый слот действительно участвует в PyTorch forward графе реального Temporal ConceptFAN, но сам оригинальный Transformer Encoder не переобучается совместно с ним и не расширяет своё self-attention число слотов**. Это осознанный экспериментальный контракт, а не уже завершённый новый сквозной архитектурный дизайн.

## 2. Данные и метод сравнения

Два **разных синтетических семейства** временных рядов, ранее разработанных отдельно: (i) не-AR импульсы «ранний/поздний»; (ii) нелинейный процесс с переключениями режимов, скачками и шумом. Для каждого использована **новая** выборка TRAIN=1200, VALID1=400, VALID2=400, TEST=600 независимых эпизодов, 16 временных точек и 12 датчиков. 3 native Transformer seed11/23/37 в каждом семействе. Все альтернативные порядки нечёткости и обычные классификаторы проходят по тем же TEST субъектам и с одинаковыми исходными K2-концептами в пределах одной инициализации.

Опубликованные конкуренты не подменялись выдуманными реализациями: используются обычный CBM с доступом ко всем 2000 размеченным случаям и временная логистическая регрессия с ранними/поздними измерениями и масками. При этом наш алгоритм использует 1200 меток для модели и 800 для независимого допуска, а обычные baselines — 2000 для обучения. Это равный **общий** объём разметки, но НЕ равная вычислительная стоимость или идентичный алгоритм оптимизации. Авторские оригинальные IT3-FLS, CSDI, IB-CBM, Res-SCBM в этом прототипе **не запускались**.

## 3. TEST/MCAR20 — базовая проверка гипотезы

AUPRC выше лучше. Все значения — среднее по 3 обучениям K2 на одной TEST-популяции соответствующего семейства. Обычные raw модели обучены один раз на соответствующем наборе меток и не выдаются за три независимых обучения.

| Метод | Импульсные ряды | Нелинейная динамика |
|---|---:|---:|
| Исходный K2 Temporal ConceptFAN | 0.59145 | 0.71394 |
| Простой TRAIN WLS temporal concept / Type-1 | **0.84307** | 0.77346 |
| Conditional flow mean / Type-1 | 0.84185 | 0.77200 |
| Conditional flow / Interval Type-2 | 0.84181 | 0.77193 |
| Conditional flow / Restricted interval Type-3 | 0.84186 | 0.77186 |
| Adaptive order (TRAIN + эталон) | 0.84186 | 0.77186 |
| Обычный all-source CBM, все 2000 меток | 0.84273 | **0.78506** |
| Raw temporal logistic, все 2000 меток | 0.83365 | 0.76391 |

**Объективный вывод:** увеличение порядка нечёткости с Type-1 до Type-2/Type-3 НЕ подтверждает существенного повышения AUPRC. Усложнение Flow относительно простого измеренного WLS тоже не помогает. На нелинейном семействе обычный all-source CBM ощутимо сильнее. На импульсных рядах качество all-source CBM сопоставимо или лучше по NLL: **0.46628**, тогда как Flow+IT3 **0.49657**. Интервалы нечёткой принадлежности здесь также нельзя выдавать за статистические доверительные интервалы прогнозной вероятности.

## 4. Синхронные пропуски и отрицательные контроли

**Исправный источник, синхронный случайный блок8:** AUPRC Type-3 **0.79660** на импульсах и **0.72249** на нелинейных рядах. Доля использования нового источника — соответственно **71.8%** и **19.8%**: система действительно отказывается во многих трудных случаях. Простой WLS даёт 0.79607 / 0.72547, all-source CBM 0.84089 / 0.78403. Увеличение порядка нечёткости не устраняет неполную наблюдаемость.

**Если все 16 шагов физического источника недоступны:** для дополнительного источника нет измерительной опоры, доля использования ровно **0** в обоих семействах, исходный прогноз K2 сохраняется.

**Известная на VALID2 инверсия датчиков 4/5/6:** новый концепт отвергнут всеми тремя обучениями; результат точно возвращается к K2 (AUPRC 0.59145 / 0.71394 при MCAR20).

**Неизвестная до TEST инверсия датчиков 4/5/6:** источник ошибочно допущен у 100% случаев. AUPRC с Flow+IT3 падает до **0.34421** вместо K2 **0.59145** на импульсах и до **0.62132** вместо **0.71394** на нелинейных рядах. Именно это опровергает заявления о «надёжности Type-3 при неизвестных сбоях» без внешней физической калибровки.

**Полный словарь K2:** модель не допускает дополнительные источники. **Прогностически полезный артефакт оборудования:** группа датчиков 9/10 может быть допущена, хотя она не является физиологическим концептом. Доступна трасса выбора, но семантической идентификации источника НЕТ.

## 5. Вероятностная часть: честная калибровка

Условный Flow получил самоконтролируемые TRAIN pseudo-target coverage около **0.80–0.846** на независимо от fit выделенных 240 TRAIN примерах для каждого найденного источника. Это покрытие сравнивает сэмплы Flow с **WLS-псевдометкой**, а НЕ с истинным физическим источником, медицинской меткой или новым больничным TEST. Называть его 80%-м «доверительным интервалом истинного концепта» запрещено.

Для Type-3 в синтетическом мире использованы искусственные независимые проверочные сигналы прибора с двумя известными режимами, дающими ширину неопределённости границы. В реальном датасете таких сигналов может не быть; тогда AUTO обязан **снизить порядок до Type-2 или Type-1**, а не подставить стандартное значение неопределённости. Большая сложность нечёткой модели не компенсирует отсутствие эталона.

## 6. Что из этого можно доказать и что пока нельзя

У нас есть точные инженерные инварианты: вложенность α-плоскостей, запрет Type-3 без независимой калибровочной опоры, разделение наблюдений и генеративных оценок, точная сумма вкладов, идентичные прежние K2-веса при расширении, нулевой дополнительный вклад без опоры.

Это НЕ доказывает: физическую/каузальную идентифицируемость неизвестного источника; статистическое покрытие Type-3-границ истинного смысла концепта; корректность при произвольной инверсии датчика; превосходство над стандартными CBM; пользу вообще от Type-3 как математического семейства.

Научный результат на этой стадии **проверочная отрицательная абляция**: в современной многокомпонентной модели главную пользу даёт само измерительное определение дополнительного источника и механизм его допуска, а не повышение порядка нечёткости. Следовательно, дальнейшее движение должно строиться вокруг **математических условий наблюдаемости и независимых проверочных якорей**, а не вокруг добавления ещё одной степени нечёткости.

## 7. Как объяснять результаты человеку

Конечное объяснение начинается со списка реально участвовавших каналов, описания временного шаблона на TRAIN, отмечает долю информации, полученную из имеющихся наблюдений, отдельно указывает восстановленные участки, сообщает изменение прогноза **в понятных процентных пунктах**, объясняет причины отказа и предупреждает, что физический смысл источника не доказан. Числа функции принадлежности и четыре α-плоскости доступны только во вкладке технического аудита, не вместо человеческого объяснения. Сами степени принадлежности не являются вероятностями событий.
