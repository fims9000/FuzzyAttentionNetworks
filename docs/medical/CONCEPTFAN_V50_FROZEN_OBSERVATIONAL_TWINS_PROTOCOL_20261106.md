## Математическая постановка: строгий контрпример, не новая теорема

Пусть \(s_t=(s_{1t},s_{2t})^\top\) — два независимых изотропных Gaussian AR(1) процесса с одинаковой автокорреляцией \(\rho=0.72\) и одинаковой шумовой дисперсией; общая амплитуда эпизода меняется в пределах [.6,1.7] и не различает оси. Два измерительных вида \(X_{A,t}=H_A s_t+\epsilon_{A,t}\), \(X_{B,t}=H_B s_t+\epsilon_{B,t}\); независимые Gaussian noise sensor .16; каждый вид имеет 2 канала, вместе 4.

Задача бинарного прогнозирования зависит **только от инвариантного** \(E_{\mathrm{total}}=E_1+E_2\). Физически поименованный целевой концепт: \(E_1=\mathrm{Var}_t(s_{1t})\), знаменатель T−1. Для любого ортогонального поворота \(R(\theta)\):
\[
s'_t=Rs_t,\quad H'_A=H_A R^\top,\quad H'_B=H_B R^\top,
\quad X'_{A/B,t}=X_{A/B,t},\quad Y'=Y.
\]
Однако \(E'_1\ne E_1\) на общем множестве эпизодов. И точный массив сгенерированных X, и y, и missing mask **побитово одинаковы** в обеих версиях мира; различается только то, что локальная физическая ось называется «источник 1». Это наблюдательная эквивалентность; никакой Transformer, fuzzy Type-3, positive AUPRC, число видов или test-time review, НЕ получающее внешней информации, не может выбрать единственную целевую семантику. Для любой не использующей референс оценки \(\hat E_1(X,Y)\):
\[
\frac{|\hat E_1-E_1|+|\hat E_1-E'_1|}{2}\ge \frac{|E_1-E'_1|}{2}.
\]
Сравнение нижней границы вычислить на untouched TEST без подбора модели.

## Положительное восстановление только в условной модели

«Внешний якорь» = **другой, аттестованный прибор**, измеряющий целевую координату на выбранных TRAIN/VALID эпизодах: \(a_t=s_{1t}+\eta_t,\ \eta_t\sim \mathcal{N}(0,.16^2)\). В «двойнике» прибор по условию измеряет \(s'_{1t}\); именно внешний аттестованный выбор физического имени ломает симметрию. Этого прибора НЕТ в четырёх входных каналах на inference; ни latent truth S, ни H не поступают в estimator. Классический \`Ridge\` восстанавливает временную траекторию из \`[measured_X×mask, mask]\` с фиксированным alpha=10 по реально измеренным TRAIN. Незаполненные значения вектора в вычислении — нули **как внутренний признак регрессора**, не как реально измеренное значение, и результат явно маркируется inferred. Модель должна сообщать о неполном наблюдении, не заявлять нового физического измерения.

TRAIN budget дорогих независимых *эпизодных* референсов заранее фиксируем в **5%, 20%, 100%** (60,240,1200 из 1200). VALID1 и VALID2 отдельно получают ровно **80** случайно выбранных assay эпизодов каждая; их стоимость (160) раскрывается отдельно. Отбор train/valid anchor эпизодов по фиксированному RNG без Y. На обоих независимых VALID: корреляция предсказания с аттестованным измерением по реально доступным timepoints \(\rho\ge .75\) и >= 80 выбранных эпизодов; иначе дать только исходный «statistical proxy / no physical label». Применение на TEST разрешено только при аттестованной паре \`(device_id, external_reference_id)\` и допустимом измерительном сдвиге.

Внешняя активность «прибор поменялся» проверяется без TEST Y: TRAIN-only межканальная pairwise-observed covariance, разбивка TRAIN на 48 bootstrap подвыборок по 250 эпизодов, порог отклонения = max(.04, q.99×1.15). TEST batch panel ≥240; если отклонение превышает — **отменить действующий сертификат калибровки**. При невидимом симметрийном повороте полная ковариация может быть одинаковой, и он останется незаметен; это необходимое предупреждение, не обещать общего anomaly detector.

**Основные заранее зарегистрированные проверки:** (1) побитовое совпадение X,Y и масок twin и ненулевое среднее |E1−E1'|; (2) нижняя граница ошибки слепого источника; (3) VALID calibration acceptance и независимая TEST корреляция/MAE энергии с целевым латентным источником на каждом twin, у всех budget и 4 devices; (4) TEST semantic-label refusal при отсутствии внешнего якоря и при смене физического \`device_id\`; (5) TEST-only amplifier shift должен отзывать сертификат по covariance monitor на 4 приборах при допустимой доле ложных тревог не выше 1 устройства из 4 на healthy; (6) raw HGB predictions/twin AP равны **точно**. Ничего не отбирать по итогам TEST. Записать все пары TEST latent **только в audit**. Сохранить 4×2×3 calibrated weights, VALID сертификаты, per-subject scores, masks, instance-level observed estimates, audit receipts.

## Что не заявлять

Данная конструкция **не** делает ConceptFAN самодостаточно физически интерпретируемой: восстановление имени оси обеспечено внешним аттестованным датчиком. Если в действительности нет такого прибора/вмешательства, любая попытка назвать q «реальной энергией источника №1» необоснованна. Значимая корреляция с шумным assay и успешные два VALID **не** гарантируют вневременную или кросс-устройственную физическую семантику. Интерпретация, построенная только через embedded train source, не имеет права расширять калиброванный класс среды без нового независимого контроля. Нельзя сравнивать anchor-Ridge с supervised predictor по неравному доступу к внешним меткам как будто это честное end-to-end SOTA.
