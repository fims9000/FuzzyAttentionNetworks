# V69 — preregistered post-V68 exploratory drift-contrastive ConceptFAN source generator

**13 November 2026. IMPORTANT:** the UCI270 batch10 TEST from V67/V68 is ALREADY INSPECTED. This protocol was committed BEFORE running V69 but AFTER inspecting that TEST and choosing its dataset. Every improvement is **post-selection exploratory**, not a new independent predictive/semantic confirmation. Do not report batch10 as untouched.

## Motivation / one architectural change

V67: ordinary global TRAIN PCA95→FastICA K4 yielded a label-free statistical source with frozen gas-label semantics that failed on batch10 (ethanol AUC VALID ~1→TEST .607, ethylene ~.993→.663) and source-only macro-F1 .445 vs raw .684. V68: global TRAIN source subspace almost identical under historical leave-one-batch-out, yet physical class associations failed. Stable global ICA geometry is an insufficient surrogate for conditional gas semantics.

V69 tests a different **TRAIN-only and outcome-label-free source objective**. Given 32 physical sensor descriptors per exposure, it favors directions with within-batch variation but penalizes directions dominated by differences between historical acquisition batches. Such directions may still represent nuisance, gas concentration, or class; **no chemical-source identification is presumed**.

## Fixed exact method

Data: original unchanged official UCI270 13,910 actual pure-gas exposures, 16 measured sensors ×8 precomputed engineered features/exposure (NOT chronological samples), original immutable source ZIP SHA256 `98fe3a30981a222dd4518fbcc3dddd45d5c0ce9b03ef6dc6fe5cf7a04cfbff5e`. Split unchanged: TRAIN batches1–7, 9,546 records; VALID batches8–9, 764; formerly viewed TEST batch10, 3,600. No new data collection, device, chemical analyzer, source mixtures or temporal neural recurrence.

1. Robust per-raw-descriptor med/IQR fit on TRAIN1–7 only, clipping [-8,8], and same two physically meaningful but NOT chronological V67 16-d sensor feature groups: the two steady-state descriptors averaged within each sensor and six transient engineered descriptors averaged within each sensor, concatenated 32 features.
2. Source K chosen **only once** via the original V67 global TRAIN-only 95% PCA total variance with cap12. This fixes K=4 for UCI270 but K is NOT supplied by gas labels, chemically named sources, VALID, or TEST. Identical K and same number of 3K fuzzy membership states as V67 isolates the directional objective.
3. Let `z_i` be 32 measured-view coordinates and `b_i` be the *acquisition batch ID* in TRAIN1–7. Batch IDs are allowed **environment metadata** in source fitting, never gas identity or ppm. `W = sum_b sum_{i in b} (z_i-mean_b)(z_i-mean_b)^T / N` and `B = sum_b n_b(mean_b-mean)(mean_b-mean)^T/N`. Set `T = W+B + ridge*I` with `ridge=0.10*trace(W)/32` (strictly positive). Compute symmetric whitened `M=T^{-1/2} W T^{-1/2}`, take its K largest eigenvalue eigenvectors (deterministic descending sort), unwhiten `A=T^{-1/2}Q_K`, normalize each column Euclidean and canonicalize signs using its largest-absolute-loading sensor group. Set source values `s_i=(z_i - TRAIN_global_mean) A`. No class/ppm labels and no target gradients enter any step. `W/T` eigenvalues in [0,1], but that does NOT prove physical gas independence or identifiability.
4. For each of K statistical source directions, fit unlabeled TRAIN Q25/Q50/Q75 and width `max(0.15,TRAIN_IQR/1.35)`; generate 3K bounded fuzzy memberships with expit. K4→12 fuzzy states (not 12 independent source mechanisms). No neural/ICA source fit in V69 new arm.
5. Original V67 source and exact signed additive classification head left unchanged: same TRAIN-only StandardScaler and C1 multinomial logistic on V69 3K source membership states; exact per-class signed additive reconstruction required |probability difference| ≤1e−9. Baselines V69 linear-K source logistic, original V67 ICA-K fuzzy/linear, V67 pooled32 logistic, original128 logistic/ExtraTrees and majority-class TRAIN. All heads TRAIN original gas identity labels only (equal TRAIN label budget), but NO gas labels are passed to the new unlabeled source basis/thresholds.
6. VALID batches8,9 and **already viewed** TEST batch10: accuracy, balanced accuracy, macro/weighted F1, OvR macro AUROC, log loss, full six-class confusions/class support. Valid-only fixed axis↔gas associations and signs via V67 `fix_semantic_alignment_from_valid` using BOTH VALID periods; TEST no rematching, all matched/unmatched gas AUC + permutation control. Include P(C) drift summary per period and full fuzzy source manifest SHA.
7. TRAIN-only seven leave-one-acquisition-batch-out reruns for V69 (new source basis, no labels), source K stability (do not force K), subspace overlap via canonical correlations on ORIGINAL TRAIN-only probe. Compare original V67's published seven-batch ICA rank/subspace stability; rank source stability and semantic association are different questions. If K varies, record each and penalize any claim of stable statistical concept count.

## Controls and falsifiers

- **Label firewall:** `fit_unlabeled(train_x,train_batch_ids)` accepts ONLY sensor features and historical TRAIN environment IDs, never labels, ppm, VALID, or TEST metadata. Permuting gas targets without changing TRAIN sensor+batch inputs leaves source manifest *bitwise unchanged*. Permuting batch IDs (keeping sensor observations unchanged) should generally modify estimated W/B and source projections; use a deterministic structured fixture for this, not an assumption of guaranteed change in real data.
- A source may remove actual gas signal if class prevalence changes across TRAIN batches. That is NOT a bug to conceal: environment-invariance alone can be antagonistic to task sufficiency.
- Increasing V69 TEST macro F1 is **not proof** that any projected coordinate equals a particular gas, nor independent validation because batch10 was already inspected.
- If original raw 128-feature models outperform, report the gap. If V69 worse than V67 K4 fuzzy, retain the negative result.
- No gas chemical identity can be confirmed from pure-gas observational classification alone. A future independent lab/controlled mixed-source intervention with calibrated reference must be required before physical naming.
- Exact additive decomposition alone has infinitely many equivalent bounded fuzzy coordinate systems (V66); V69 does not overturn this theorem or prove its stronger assumptions.
