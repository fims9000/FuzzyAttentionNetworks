# ConceptFAN V57 — frozen calibrated concept value + newly fitted native source head

**Pre-TEST protocol, 13 Nov 2026.** Branch `experiment/conceptfan-v57-attested-value-20261113`, based on audited V56. Parent hypothesis: automatically discovered statistical concepts can be conditionally associated with independently measured units. **The predicted risk coefficient must be trained on exactly the same numeric concept definition used in inference.**

## Registered architecture
1. Discover up to 3 masked operator candidates using outcome-blind TRAIN-only V54, then fit V55's bounded convex fuzzy activation and risk coefficients on TRAIN Y. Keep base K2 frozen and real native torch signed bottleneck.
2. Require V56's *independent assay-gated* source selection: 190 purchased TRAIN assay readings, plus 100+100 fresh assay readings in two independent VALID cohorts, with two separate predictive VALID gates. Source identity remains statistical and cohort-scoped; reference IDs are declared, not cryptographically attested.
3. For that selected candidate and **only** it, use its TRAIN-fitted nonnegative q→assay regression `E_hat=max(0, slope*q+intercept)`, with TRAIN-purchased assay median and IQR (`max(IQR,.1)`) to define a deterministic bounded concept membership `q_assay=sigmoid((E_hat−median)/IQR)`. Use support>=.5; absent source is exactly neutral, q=.5.
4. **Never use V55 gamma with this new q scale.** Fit a *new single gamma on TRAIN labels only* using frozen K2 logits and `q_assay`. Independently admit this new head on disjoint VALID1/VALID2 Y using unchanged conservative V28 99%-bootstrap policy, no TEST. At most one joint concept contributes to the native signed head; when risk gate fails, return bitwise K2.
5. The complete numerical source contract includes: exact V55 candidate ID, source sensor/lag/operator, external device ID and reference ID, q→assay regression, TRAIN assay median/IQR, **new TRAIN gamma**, two independent VALID receipts and source-cohort monitor. Inference on wrong device/reference/candidate or inconsistent contract must abstain; q and risk never silently substituted.
6. At TEST, do not use assay, latent sources or Y before predictions. Apply the frozen V56 source-only cohort drift monitor (mean q, no Y); if out-of-scope or missing source, exactly return K2. For valid episodes, compute `q_assay` from observed sensor q, then pass it through the **native PyTorch signed ConceptFAN head**, verify signed decomposition independently.

## Stop criteria / scientific boundaries
- V57 may lose AUPRC or NLL compared with V55/V56 or engineered + q logistic. This must remain a negative finding without post-TEST threshold adjustment.
- Calibration is conditional on a declared, **synthetically simulated** independent measurement instrument. An assay correlation plus matching string reference IDs cannot establish biological/causal source identity or general real-world trust. The observational equivalence counterexample V50 remains.
- Gate on physical-value q only when the same q was used to fit the risk coefficient; never transplant V55 gamma to the new scale. A broken or missing source contract **must** return K2, not an unverified source.
- No external clinical transfer, causal intervention, universal nonlinear program induction or SOTA claim is authorized by these synthetic experiments.
