# ConceptFAN V62: untouched UCI HAR cross-modality, conditional gyro concepts

**Frozen 13 November 2026 BEFORE fetching UCI HAR inertial sample values, TEST labels or running V62 model training.** New research branch \`experiment/conceptfan-v62-uci-har-fresh-cross-modality-20261113\`. Based on V61R stability repair. The task and official subject split are defined **from public metadata only**; previous BIDMC/VitalDB subjects/results are not used to select any V62 model.

Original dataset: [UCI Human Activity Recognition Using Smartphones](https://archive.ics.uci.edu/dataset/240/human+activity+recognition+using+smartphones) DOI [10.24432/C54S4K](https://doi.org/10.24432/C54S4K), CC-BY-4.0. **30 subjects**, six video/protocol-labeled activities, 128-sample/2.56s overlapping 50Hz inertial windows; original official training split **21 people/7352 windows**, official test **9 disjoint people/2947 windows**. Use original body acceleration and angular-velocity time series only (NOT the pre-computed 561 feature vectors). Official TEST individual labels and feature values are not consulted before all V62 training and gate decisions are frozen.

## Falsifiable global question
If the typed measured-program FAN architecture is truly reusable, can *angular velocity measured by a gyroscope* contribute something useful to a frozen accelerometer-only concept head on an independently labeled human-activity task? This is more defensible than calling correlated medical monitor channels independent physiological sources. It still cannot establish causal sensor identities or universal superiority.

## Predeclared binary tasks
- **Primary:** walking upstairs (official class **2**) versus walking downstairs (class **3**); exclude other four activities from every split *before model fitting*. Label \(y=1\) for upstairs, 0 for downstairs. Each subject must stay entirely in one partition.
- **Negative-control:** sitting (class **4**) versus standing (class **5**); label \(y=1\) for standing. Also evaluated on the same predeclared subject allocation; gyro novelty may fail for relatively static classes.
- Official UCI TEST persons (9) remain completely untouched until after TRAIN fits and VALID decisions; do not use test class balance for split or tuning. Original 21 subject TRAIN people deterministically shuffled by NumPy seed **20266213**, allocated **13 TRAIN / 4 VALID1 / 4 VALID2**; any absent class in a split is a reported \`NOT_ESTIMABLE\` outcome, NOT reason to change split. Within-person windows overlap 50% and are NOT independent. Patient-group bootstrap from V61R generalizes to **participant groups**.

## Fixed physical measured channels and causal program translation
- Load and verify original UCI \`train|test/Inertial Signals/body_acc_{x,y,z}_{train|test}.txt\`, \`body_gyro_{x,y,z}_{train|test}.txt\`, subject and activity label files. Enforce actual 128 points per row, all finite, official distinct participant groups, no use of UCI precomputed 561-feature vector, no use of target labels in operator compiler.
- From each time-step \(\tau\) compute 3 named, physically sourced traces:
  - **anchor channel 0**, body accelerometer vector magnitude \(a(\tau)=\sqrt{a_x^2+a_y^2+a_z^2}\);
  - **candidate gyro channel 1**, gyroscope angular-speed magnitude \(\omega(\tau)=\sqrt{\omega_x^2+\omega_y^2+\omega_z^2}\);
  - **candidate gyro channel 2**, signed gyroscope \(y\)-axis angular speed \(\omega_y(\tau)\).
- Non-overlapping block-mean each trace over eight successive original samples -> a **16×3** causal measured program window. This does not introduce future values beyond the labeled window, which is contemporaneous activity recognition, not 60-second forecasting.
- Normalize each of 3 channels by **TRAIN-only observed median and IQR floor 0.1**, clip [-8,8], all observed. Frozen preprocess passport, no user features or labels read during statistics. Source compiler is exactly V61R typed 24-program library with TRAIN patient-fold variation/coverage/redundancy screen, but metadata channel names adapted to \`BODY_ACC_NORM\`, \`BODY_GYRO_NORM\`, \`BODY_GYRO_Y\`. **All claimed novel sources must use only channels 1/2**; gyroscope is a different physical sensor, but this does not establish an independent *causal mechanism* of activity.
- Use V61R TRAIN-only Ridge(alpha25) regression of gyro program scores from 6 acceleration-only programs; canonical rounding 12 decimals, conditional source shortlist <=6 selected outcome-blind by TRAIN variation/coverage plus distinct source group, not by Y-trained gamma. Monitor unavailable input means neutral q and exactly zero signed contribution.

## Model controls, admission, stress
- Native PyTorch **accelerometer-only ProgramFAN** trained with equal total weight per TRAIN participant; frozen as baseline.
- V61R signed additive **conditional gyro residual ProgramFAN** (two genuinely different train initializations 11/23 with std .03), up to six gyro-only typed programs and no latent/raw-to-risk shortcut. Distinct source definitions and signed coefficients are audited.
- Two independently isolated VALID sets (4 persons each) both must show patient-macro NLL gain ≥.005, one-sided 99% 399 *whole-subject* bootstrap lower bound >0, >=50% episode source support, and source benefit > conditional 49 within-subject accelerometer-score-quartile shuffled null 95th gain +.003 with >=25% swapped source rows. If not, **deploy exact frozen accel-only head**, keep ungated candidate results separately and do not promote after seeing TEST.
- Strong simple logistic baselines (all TRAIN Y and same person weights): (i) accelerometer-only 3-axis 128-point raw signal means/variances (plus **16×3** block means), (ii) all raw accelerometer+gyro six axes with identical time-domain representation, (iii) same compiled normalized program values+mask bits accel-only and all sensors. Add transparent gyroscope-only logistic as ablation. All have no TEST fitting, validation threshold search or user-ID predictor input.
- Predeclared TEST stress: natural unmodified signal; gyro totally missing; accelerometer totally missing; gyro 1.5× positive multiplicative gain; extra 20% random numerical block dropout. For each, recompute outcome-blind programs from the stressed measured channels, no re-calibration. All methods receive the identical allowed stressed inputs in their respective modality; logistic raw-axis controls receive corresponding raw-axis sensor dropout/gain. A failed source gate means unchanged accel-only deployed risk under all stresses.
- Metrics: TEST AUPRC, binary cross-entropy NLL, accuracy at fixed .5 threshold, whole-person macro NLL, real participant counts, source definition passports, observed training source dispersion, patient-cluster 95% descriptive paired bootstrap vs same-program and full-axis logistic, audit of bitwise head fallback and signed gamma contributions. Nine held-out people, NOT 2947 independent participants. Two train inits do not increase external cohort size.
- All modeling code and dataset recipe remain reproducible; raw participant inertial streams or per-participant risk arrays are NOT uploaded to public GitHub artifacts. Report only group summaries, source checksums and provenance. Attribute CC-BY-4.0 to source.

## Honest scientific limits
- Original UCI HAR window generation includes filtering and 50% overlap; adjacent samples/labels are dependent. Official TEST subject separation is valid but only nine people and one device model, so global generalization remains limited.
- The tasks are contemporaneous activity recognition by **video/protocol labeled** movement, not independent physics/clinical source attestation. Gyroscope and accelerometer share a moving phone and may have coupled motion and acquisition artifacts.
- If no conditional gyro source survives the *two participant VALID +49 null* gates, this is a **genuine negative source discovery** on a truly new external dataset. Do not weaken thresholds or relabel source identity to manufacture success. If proposed model improves TEST but was refused by VALID, report both and retain refusal.
- V62 is a first unseen *cross-modality feasibility test* but was designed after inspecting prior BIDMC/VitalDB results. It is not a rigorous external replication across many physical devices or tasks; multiple comparisons across binary tasks are exploratory and not corrected for multiplicity.
